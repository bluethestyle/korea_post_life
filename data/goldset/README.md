# 정답셋

추출 정확도를 재는 기준 자료입니다(기획 10.2). 추출기와 따로 만들어야 지표가 의미 있어서, 초안은 추출기를 만드는 쪽이 아닌 카본(Gemini)이 공시 문서 원문만 보고 작성했고, 원문과 대조해 검수했습니다.

| 파일 | 내용 |
| --- | --- |
| `hanwha_goldset.jsonl` | 한화생명 시그니처 H통합보험. 25항목 (보장금액·면책·감액 14, 가입조건 6, 결합 제약 3, 문서에 없음 2). 번호 101~125 |
| `epost_goldset.jsonl` | 우체국간편한건강보험 2606, 우체국통합건강보험 2504. 85항목 (가입조건 20, 보장금액·면책·감액 30, 보험료 25, 결합 제약 10). 이 가운데 9항목은 문서에 답이 없는 질문 |

- 근거 문서는 우체국보험 공시실의 상품요약서와 사업방법서입니다. 쪽수는 표지를 포함한 PDF 쪽 번호입니다.
- `검수` 열은 확인 방법입니다: 원문 직접 대조 / 정답 숫자가 해당 쪽에 있음(기계 대조) / 부재 확인.
- 질병코드 15항목은 약관 별표가 필요해 아직 없습니다. 삼성화재 항목은 카본 초안을 받은 뒤 더합니다.
- 우체국 상품요약서에는 특약별 월 보험료 예시표가 없습니다. 그래서 보험료 영역은 해약환급금 예시표의 경과기간별 납입보험료, 할인율, 예정이율로 채웠습니다.
- 한화생명 25항목은 정답이 모두 원문과 맞았습니다. 고친 것은 표기뿐입니다: 특약 이름 2건에서 빠진 대괄호와 `(고지통합)`·`(연1회)`를 원문대로 되살렸고(107, 113), 종 표기 1건을 질문에 맞게 좁혔습니다(116). 한화생명은 같은 특약이라도 간편가입형과 일반·건강가입형의 금액표가 따로 있어, `상품과종`에 적힌 가입유형 범위까지 맞아야 정답으로 칩니다.
