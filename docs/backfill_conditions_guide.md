# 초기 적재 가입조건 판독 지시문

이 지시문은 초기 적재에서 사업방법서의 주계약 가입조건(가입나이, 보험기간, 납입기간, 가입한도)을 읽는 판독자(Claude 에이전트)가 일감 하나를 받아 값을 내는 방법을 적은 것이다. 같은 일감을 판독자 둘이 따로 읽고, 코드가 두 판독을 견주고 그 쪽의 글자와 대조한다. 두 판독이 같고 기계 검사를 통과한 종형만 확정되므로, 확신이 없으면 지어내지 말고 "모름"으로 둔다.

화면의 가입 관문 비교는 이 값으로 "몇 살까지 가입할 수 있는가"를 판정한다. 그래서 종형마다 맞는 표를 고르는 것이 가장 중요하다. 숫자를 정확히 옮겨도 다른 형이나 다른 심사유형의 표를 읽었으면 틀린 값이다.

범위는 주계약(사업방법서에서는 "기본계약"이라고 적기도 한다)뿐이다. 특약의 가입나이와 특약 사이의 결합 제약은 읽지 않는다.

견주는 코드는 `src/postlife/extract/reader_conditions.py`, 견주는 도구는 `scripts/compare_condition_readers.py`다. 급부 판독 지시문(`docs/backfill_reader_guide.md`)과 방식이 같다.

## 1. 받는 것

- 일감 파일(JSON) 하나. 형식은 `가입조건일감/1`이다.
  - `일감`: 일감 이름. 예: `6AFMG_SIMPLE`
  - `사업방법서`, `상품요약서`: 각각 `PDF`(판독자가 열어 볼 파일), `글자`(코드가 대조에 쓰는 쪽 글자 파일), `쪽수`. 쪽 번호는 PDF의 쪽 순서와 같다.
  - `쪽범위`: 가입나이 표가 있는 쪽의 범위. 값을 읽은 쪽이 이 범위 밖이면 기계 검사가 표시한다.
  - `쪽안내`: 세목 표, 가입나이 표의 제목이 있는 쪽, 의무가입과 기타 항목의 쪽. 길잡이일 뿐이고, 어느 표가 어느 종형의 것인지는 판독자가 PDF를 보고 정한다.
  - `종형`: 읽을 종형 목록. 종형마다 `종형ID`, `공시상품코드`, `종형명`, `심사유형`, `간편고지약칭`, `비교역할구분`, `환급유형`. 종형명은 사업방법서 세목 표의 형, 종, 심사유형 표기를 이은 것이다.
- 판독 파일을 쓸 폴더와 판독자 이름(예: `sonnet`, `opus`), 꼴 검사를 돌릴 도구 폴더와 파이썬 경로. 의뢰문에 적혀 있다.

## 2. 내는 것

판독 파일 하나를 `<폴더>/<일감>.<판독자>.json`으로 쓴다(예: `6AFMG_SIMPLE.sonnet.json`). 일감의 종형마다 한 줄씩, 빠짐없이 낸다. 여러 종형이 표 하나를 함께 쓰면 표는 `표` 목록에 한 번만 적고, 종형마다 그 표의 이름을 적는다.

```json
{
  "형식": "가입조건판독/1",
  "일감": "X1_SIMPLE",
  "판독자": "sonnet",
  "표": [
    {"표": "간편2형", "근거쪽": 6, "근거낱말": ["가나간편형", "2형"],
     "줄": [{"쪽": 6, "성별": "구분없음", "보험기간": "80세만기", "납입기간": "20년납",
             "최저나이": 20, "최고나이": 56, "최고나이식": "76-납입기간"}],
     "한도없음": true, "한도": [], "모름": []}
  ],
  "종형": [
    {"종형ID": "GANA_X1_aaaaaa", "표": "간편2형", "모름": []}
  ]
}
```

다 쓴 뒤에 꼴 검사를 돌려 "꼴 문제 없음"이 나오는지 본다. 이 검사는 칸 이름과 허용값, 같은 열쇠의 줄이 두 번 나오는지, 빠지거나 남는 종형, 어느 종형도 쓰지 않는 표만 본다. `<도구 폴더>`와 `<파이썬>`은 의뢰문에 적힌 경로다(리포의 `src/postlife`와 `scripts/compare_condition_readers.py`를 복사해 둔 폴더).

```bash
PYTHONPATH=<도구 폴더> <파이썬> <도구 폴더>/compare_condition_readers.py <일감 파일> --check <판독 파일>
```

## 3. 읽는 순서

1. 일감 파일을 연다. 종형 목록과 종형명, 쪽안내를 확인한다.
2. 세목 표가 있는 쪽(대개 사업방법서 2쪽)을 연다. 종형명에 든 형(예: 2형), 종(예: 1종), 심사유형(예: 통합간편심사형, 일반심사형), 간편심사유형(예: 315간편심사형)이 무엇을 가리키는지 본다.
3. 쪽안내에 적힌 가입나이 표 제목 쪽을 모두 연다(Read 도구에 `pages`로 쪽 번호를 준다. 예: `pages: "11"`). 표 제목과 표 위아래의 주석을 보고 종형마다 맞는 표를 고른다(5절).
4. 고른 표에서 기본계약(주계약) 줄의 보험기간, 납입기간, 가입나이를 읽는다(6절). 표가 다음 쪽으로 이어지면 다음 쪽도 연다.
5. 기본계약의 가입한도를 찾는다(7절).
6. 판독 파일을 쓰고 꼴 검사를 돌린다.

값은 PDF에서 읽는다. 쪽 글자 파일은 표가 글자로 풀리며 칸이 뒤섞여 있어 값을 읽는 데 쓰지 않는다.

하지 않을 것

- 다른 판독자의 파일을 보지 않는다. 같은 일감을 다시 읽어 고칠 때도 자기 파일만 고친다.
- 원문 문장을 옮겨 적지 않는다. 숫자, 기간 글자, 허용값, 표 제목의 짧은 낱말만 적는다.
- 특약 줄을 읽지 않는다. 기본계약과 같은 칸에 묶인 특약 이름이 있어도 기본계약의 값만 적는다.
- 갱신계약의 가입나이를 적지 않는다. 표가 최초계약과 갱신계약으로 나뉘면 최초계약 줄만 읽는다.
- 일감에 없는 종형을 더하지 않는다.

## 4. 칸과 허용값

### 4.1 표

| 칸 | 값 | 비울 때 |
| --- | --- | --- |
| `표` | 판독자가 붙인 짧은 이름(10자 이하). 종형 줄에서 이 이름으로 가리킨다 | 비우지 않는다 |
| `근거쪽` | 표 제목이 있는 쪽(정수) | 비우지 않는다 |
| `근거낱말` | 이 표가 그 종형의 것이라고 본 낱말 1~5개. 표 제목에서 뽑고, 하나에 20자 이하(5절) | 비우지 않는다 |
| `줄` | 기본계약의 가입나이 줄 목록(4.2절) | 모름에 `줄`이나 `표`의 이유가 있을 때만 `[]` |
| `한도없음` | 기본계약의 가입한도가 문서에 적혀 있지 않으면 `true` | 비우지 않는다 |
| `한도` | 가입한도 목록(4.3절) | 한도없음이 `true`면 `[]` |
| `모름` | `[{"칸", "이유"}]`. 칸은 `표`, `줄`, `한도` 가운데 하나, 이유는 80자 이하 | `[]` |

### 4.2 줄

성별, 보험기간, 납입기간이 하나씩 정해진 줄이다. 이 셋이 같은 줄은 한 표에 두 번 나오면 안 된다.

| 칸 | 값 |
| --- | --- |
| `쪽` | 값을 읽은 쪽(정수) |
| `성별` | `구분없음`, `남자`, `여자`. 가입나이 칸이 남녀로 나뉘면 남자 줄과 여자 줄을 따로 낸다. 한 표에 `구분없음` 줄과 남녀 줄을 섞지 않는다 |
| `보험기간` | 한 값. `80세만기`, `20년만기`, `20년`, `종신` 꼴. 문서에 적힌 글자대로 적는다("20년만기"로 적혀 있으면 `20년만기`, "20년"으로 적혀 있으면 `20년`) |
| `납입기간` | 한 값. `20년납`, `60세납`, `전기납`, `일시납` 꼴. 납입주기(월납)는 적지 않는다 |
| `최저나이` | 가입나이의 아래 끝(정수). "만19세"는 `19`, "0세"는 `0` |
| `최고나이` | 가입나이의 위 끝(정수). 식으로 적혀 있으면 계산한 값 |
| `최고나이식` | 최고나이가 식으로 적혀 있을 때만: `<숫자>-납입기간` 또는 `<숫자>-보험기간`. 아니면 `""` |

### 4.3 한도

나이 구간(필요하면 기간)마다 하나다.

| 칸 | 값 |
| --- | --- |
| `쪽`, `문서` | 한도를 읽은 쪽과 문서(`사업방법서` 또는 `상품요약서`) |
| `최저나이`, `최고나이` | 그 한도가 걸리는 나이 구간. 아래 끝이 적혀 있지 않으면 `0`, 위 끝이 적혀 있지 않으면(예: "61세 이상") `null` |
| `보험기간`, `납입기간` | 한도가 기간에 따라 갈릴 때만 그 기간. 아니면 `""` |
| `최저금액만원` | 가입금액의 아래 한도(만 원). 적혀 있지 않으면 `null` |
| `최고금액만원` | 가입금액의 위 한도(만 원). "3억원"은 `30000`, "1,000만원"은 `1000` |

### 4.4 종형

| 칸 | 값 |
| --- | --- |
| `종형ID` | 일감의 종형ID 그대로 |
| `표` | 그 종형이 쓰는 표의 이름. 맞는 표를 고르지 못하면 `""` |
| `모름` | 표를 고르지 못했으면 `[{"칸": "표", "이유": "…"}]` |

## 5. 표 고르기

사업방법서는 상품(심사유형), 형(해약환급금 지급형과 미지급형 따위), 때로는 종마다 가입나이 표를 따로 둔다. 표 제목에 그 표가 어느 상품과 형의 것인지 적혀 있다.

- 종형명의 형 번호, 심사유형 이름과 표 제목의 낱말이 맞는 표를 고른다. 형 구분이 없는 상품(예: 일반심사형만 있는 세목)은 상품 이름이 맞는 표를 고른다.
- `근거낱말`에는 표 제목에서 그 종형을 가리키는 낱말을 적는다. 예: `["가나간편형", "2형"]`. 형 번호와 종 번호("2형", "1종")는 종형명에 든 표기 그대로 적는다. 코드는 근거낱말이 근거쪽 글자에 있는지, 형이나 종 번호를 적은 근거낱말이 종형명에 있는지 본다. 종형명에 든 근거낱말이 하나도 없으면 확정되지 않는다.
- 간편심사유형(예: 305, 315, 325)이나 고지 유형(예: 입원고지, 수술고지)마다 표가 따로 있는지, 여러 유형이 한 표를 함께 쓰는지는 표 제목과 주석으로 확인한다. 함께 쓰면 종형마다 같은 표 이름을 적는다.
- 종(예: 납입면제 미적용형, 납입면제형)으로 표가 갈리지 않으면 종 번호는 근거낱말에 넣지 않아도 된다.
- 맞는 표가 없거나 둘 이상이면 그 종형의 `표`를 비우고 `모름`에 이유를 적는다.

지어낸 예. 세목 표에 1형(지급형)과 2형(미지급형)이 있고, 가입나이 표가 둘 있다.

- 5쪽 제목: `[가나건강보험(가나간편형)-1형(지급형)]`
- 6쪽 제목: `[가나건강보험(가나간편형)-2형(미지급형)]`

종형명이 "가나간편형 2형(미지급형) 1종(…) 315간편형"이면 6쪽의 표를 고른다. 근거쪽 `6`, 근거낱말 `["가나간편형", "2형"]`.

## 6. 가입나이 줄 읽기

### 6.1 기본계약 줄 찾기

표의 맨 앞 칸(순번이나 보장)에 기본계약 이름이 특약 이름들과 함께 묶여 있는 경우가 많다. 기본계약이 든 묶음의 보험기간, 납입기간, 가입나이 칸을 읽는다. 다른 묶음(다른 순번)의 특약 줄은 읽지 않는다.

### 6.2 합쳐진 칸 펼치기

보험기간이나 가입나이 칸 하나가 여러 줄에 걸쳐 합쳐져 있으면 그 값이 걸친 줄마다 적용된다. 납입기간이 "10, 15, 20년납"처럼 한 칸에 나열되어 있으면 납입기간마다 줄을 따로 낸다.

지어낸 예

| 보험기간 | 납입기간 | 가입나이 |
| --- | --- | --- |
| 80세만기 | 10년납 | 0세~70세 |
|  | 20년납 | 0세~60세 |
| 90세만기 | 10년납, 20년납 | 0세~70세 |

줄은 넷이다: 80세만기 10년납 0~70, 80세만기 20년납 0~60, 90세만기 10년납 0~70, 90세만기 20년납 0~70.

### 6.3 식으로 적힌 최고나이

가입나이가 "20세~(76-납입기간)세"처럼 식이면 납입기간의 햇수를 빼서 최고나이를 계산하고, 식을 `최고나이식`에 적는다.

지어낸 예

| 보험기간 | 납입기간 | 가입나이 |
| --- | --- | --- |
| 80세만기 | 20년납, 30년납 | 20세~(76-납입기간)세 |

```json
[{"쪽": 6, "성별": "구분없음", "보험기간": "80세만기", "납입기간": "20년납", "최저나이": 20, "최고나이": 56, "최고나이식": "76-납입기간"},
 {"쪽": 6, "성별": "구분없음", "보험기간": "80세만기", "납입기간": "30년납", "최저나이": 20, "최고나이": 46, "최고나이식": "76-납입기간"}]
```

- 식이 "(80-보험기간)"이면 보험기간의 햇수(예: 20년만기의 20)를 빼고 `최고나이식`은 `80-보험기간`.
- 납입기간이 "전기납"이고 식이 납입기간을 빼면, 전기납은 보험기간과 같으므로 보험기간의 햇수(N년만기의 N)를 뺀다.
- 코드는 식의 숫자("76-납")가 그 쪽에 있는지, 계산이 맞는지 본다. 식이 없는 줄은 최저나이와 최고나이가 "N세"로 그 쪽에 있어야 한다.

### 6.4 성별로 나뉜 표

가입나이 칸이 남자와 여자로 나뉘어 있으면 같은 기간에 남자 줄과 여자 줄을 따로 낸다. 지어낸 예: "90세만기 20년납 남자 15~65세, 여자 15~70세" → 줄 둘(`성별: "남자"`, `성별: "여자"`).

### 6.5 가입최저나이와 가입최고나이를 따로 적은 표

"가입최저나이: 만15세"를 한 줄로 적고 가입최고나이를 표로 적은 문서도 있다. 칸마다 줄 하나를 내고, 최저나이에는 가입최저나이를, 최고나이에는 그 칸의 나이를 적는다.

## 7. 가입한도

기본계약의 보험가입금액 한도를 찾는다. 사업방법서의 "보험가입금액의 한도" 절, 가입나이 표 위아래의 문장, 의무가입과 기타 항목, 상품요약서의 자격요건이나 가입나이 표 앞뒤를 본다.

- 특약의 한도(예: 의무가입 특약의 가입금액 범위, 특정 특약의 고정 가입금액)는 기본계약의 한도가 아니다. 적지 않는다.
- 건강상태나 직업에 따라 가입금액을 제한할 수 있다는 식의 숫자 없는 문장은 한도가 아니다.
- 기본계약의 한도가 어디에도 적혀 있지 않으면 `한도없음: true`, `한도: []`.

지어낸 예. 기타 항목에 "가나보장(기본계약)의 가입금액은 가입나이 60세 이하 1,000만원 이내, 61세 이상 500만원 이내"라고 적혀 있다.

```json
"한도없음": false,
"한도": [{"쪽": 9, "문서": "사업방법서", "최저나이": 0, "최고나이": 60, "보험기간": "", "납입기간": "",
          "최저금액만원": null, "최고금액만원": 1000},
         {"쪽": 9, "문서": "사업방법서", "최저나이": 61, "최고나이": null, "보험기간": "", "납입기간": "",
          "최저금액만원": null, "최고금액만원": 500}]
```

같은 기간 범위 안에서 한도의 나이 구간이 겹치면 기계 검사에 걸린다.

## 8. 모름

어느 칸을 읽지 못했으면 `모름`에 `{"칸": "<표, 줄, 한도>", "이유": "<80자 이하>"}`를 적는다. 이유에는 원문 문장을 옮기지 않고 무엇이 막혔는지만 적는다. 예: `"2형 표의 기본계약 칸이 두 쪽에 걸쳐 납입기간이 둘로 읽힘"`, `"가입한도 문장이 기본계약 것인지 특약 것인지 알 수 없음"`. 모름은 틀린 값보다 낫다. 모름이 있는 종형은 메인 세션이 원문을 보고 정한다.

- 표의 줄 가운데 일부만 읽지 못했으면 읽은 줄은 적고 `모름`에 `줄`과 이유를 적는다.
- 종형에 맞는 표를 고르지 못했으면 그 종형의 `표`를 비우고 종형의 `모름`에 `표`와 이유를 적는다.

## 10. 견줌과 판정(메인 세션이 하는 일)

판독이 끝나면 메인 세션이 두 판독 파일을 견준다. 판독 폴더에서 `<일감>.<판독자>.json`을 찾는다.

```bash
PYTHONPATH=src python scripts/compare_condition_readers.py <일감 파일> --answers <판독 폴더> --readers sonnet opus \
  --out <값 파일.jsonl> --report <견줌 결과.json> --rows <행.jsonl>
```

- 종형마다 두 판독이 고른 표의 줄(성별, 보험기간, 납입기간별 최저와 최고 나이)과 한도(한도없음 포함)를 견준다. 두 판독이 같고, 두 판독 모두 기계 검사의 문제와 표시가 없고, 모름이 없으면 자동판정이 확정이다. 근거쪽이 다른 것은 결과에 적기만 하고 판정을 막지 않는다.
- 기계 검사는 두 판독이 같은 방식으로 틀리는 것을 잡는다: 근거낱말이 근거쪽에 있는가, 형이나 종 번호를 적은 근거낱말이 종형명에 있는가, 최저와 최고 나이와 기간 글자가 값을 읽은 쪽에 있는가, 최고나이식의 숫자가 그 쪽에 있고 계산이 맞는가, 최저나이가 최고나이보다 크지 않은가, "N세만기"인데 최고나이가 N 이상이 아닌가, 값을 읽은 쪽이 일감의 쪽 범위 안이고 근거쪽보다 앞이 아닌가, 근거쪽부터 값을 읽은 쪽까지 "기본계약"이나 "주계약" 글자가 있는가, 한도 금액과 나이가 그 쪽에 있고 나이 구간이 겹치지 않는가.
- 그 밖의 종형은 메인 세션이 PDF의 그 쪽을 보고 값 파일의 `판정` 칸을 채운다: `확정`, 판독자 이름(그 판독의 값을 씀), `수정`(`판정값`에 판독 값과 같은 꼴로 고친 값), `검토 대기`. 판정을 채운 값 파일로 행만 다시 만들 때는 `--values <값 파일> --readers sonnet opus --rows <행.jsonl>`.
- 값 파일에는 원문 구절이 없다. 숫자, 기간 글자, 표 제목의 짧은 낱말과 종형명만 있고, 판독자가 쓴 모름 이유는 싣지 않는다(모름은 칸 이름만 남는다).
- 행 만들기(`reader_conditions.build_rows`)는 `conditions.build_rows`와 조건행ID 규칙을 그대로 쓴다. 주계약 행이라 특약ID는 비운다. 한도가 나이 구간에 따라 갈리면 한도가 바뀌는 나이에서 행을 나누고, 구간마다 구간최대가입금액만원을 적는다.
