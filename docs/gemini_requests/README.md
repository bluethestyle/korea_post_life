# 제미나이 요청문 틀

파이프라인과 따로 제미나이에 맡긴 일의 요청문입니다. 앞쪽은 제미나이(Gemini 웹과 구독 패널)에 넘긴 교차 확인과 검토 요청이고, 뒤쪽은 사용자 PC의 Antigravity(브라우저 에이전트 포함)용 화면 점검과 화면 구현 지시문입니다. 사람이 요청문과 첨부를 넣고 답을 받아 옮겼습니다. 받은 결과는 `data/crosscheck/`와 `data/goldset/`에 있고, 경과는 `docs/progress.md`와 `docs/antigravity_log.md`에 적었습니다.

자료가 길게 붙는 요청은 지시 부분과 자료의 앞 몇 줄만 남겼습니다. 첨부했던 발췌 PDF는 공시 문서 원본이라 저장소에 두지 않습니다.
