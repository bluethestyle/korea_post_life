# 제미나이 요청문 틀

파이프라인과 따로 제미나이(Gemini 웹)에 맡긴 일의 요청문입니다. 사람이 요청문과 첨부를 넣고 답을 받아 옮겼습니다. 받은 결과는 `data/crosscheck/`와 `data/goldset/`에 있고, 경과는 `docs/progress.md`에 적었습니다.

자료가 길게 붙는 요청은 지시 부분과 자료의 앞 몇 줄만 남겼습니다. 첨부했던 발췌 PDF는 공시 문서 원본이라 저장소에 두지 않습니다.

| 파일 | 맡긴 일 | 첨부 |
| --- | --- | --- |
| `01_정답셋과_교차확인.md` | 우체국 직전 개정판 추출 결과 교차 확인, 한화·삼성화재 정답셋, 종형 속성 확인표 | 요약서·사업방법서 PDF |
| `05-1`~`05-3_종형속성_*.md` | 종형(가입유형)별 속성과 알릴 의무 문항. 처음에 세 문서를 한 번에 주었다가 답을 못 받아 문서별로 나눔 | 사업방법서(삼성화재는 필요한 쪽만 뽑은 발췌본) |
| `06_가입나이표_재확인.md` | 글자로 풀린 표로만 대조했던 가입나이 9항목을 PDF 표에서 다시 읽기 | 해당 쪽 발췌 PDF |
| `07_추출결과_표본대조.md` | 한화 추출 결과 63줄을 원문과 대조(틀린 줄, 빠진 급부) | 표본 특약 쪽 발췌 PDF |
| `08_급부구조화_THEFIT.md`, `11_급부구조화_새로고침.md` | 삼성화재 급부 표를 지급률·감액·면책·한도로 구조화(각 6묶음) | 없음(자료를 글로 붙임) |
| `09_코드검토.md` | 추출·검증 코드에서 틀린 값을 통과시키거나 맞는 값을 버리는 곳 찾기 | 줄 번호를 붙인 소스 묶음 글 파일 |
| `10_표준담보분류.md` | 매핑 대기 388종류를 기존/신규/대상외로 분류 | 없음 |
| `12_가입조건정답셋_한화.md` | 한화생명 가입조건과 특약 제약 정답셋 24항목(번호 201~224). 구독 패널의 제미나이에 넘김 | 없음(사업방법서 전문과 요약서의 가입조건 쪽을 글로 붙임) |

요청문을 쓸 때 지킨 것은 `docs/handoff.md` 6절에 적었습니다. 12번부터는 Claude Code에서 구독 패널의 제미나이에 넘긴 요청이고, 역할 나눔과 검수 기준은 `CLAUDE.md`의 "제미나이와 서브에이전트 운용"에 있습니다.
