## 1. 레이아웃 (렌더링한 프레임으로 확인)

### 원인별 규칙

여러 장면에서 같은 원인이 되풀이됩니다. 건별로 고치는 것과 함께 아래 규칙을 장면 전체에 적용합니다.

- **규칙 A. 줌 동안 상단 바가 제목 바에 가려지거나 가장자리에 잘림** (5, 6, 16번, 같은 원인의 이웃 요소 잘림 2, 3, 15번). 열 하나나 패널 하나로 줌하면 화면 위쪽에 둔 자원 바와 규격 바가 제목 바(720p y 0~65) 아래로 들어가거나 좌우 가장자리 밖으로 나갑니다. 상단 바는 카메라와 함께 움직이지 않는 HUD 레이어에 두거나, 줌하는 동안 페이드아웃하고 줌이 끝난 뒤 다시 보여 줍니다. 줌 중심과 배율은 화면에 남길 요소의 경계 박스가 제목 바 아래, 자막 바 위, 좌우 가장자리 안에 들어오도록 정합니다.
- **규칙 B. 3D 구도에서 빌보드 배지가 대상을 덮음** (11, 12, 13, 18번). 배지를 막대나 노드 바로 앞에 두면 카메라 각도에 따라 대상의 몸통을 덮습니다. 배지는 대상의 바깥쪽(막대 윗면보다 위나 옆)에 두고 지시선으로 잇습니다. 배지끼리, 배지와 배너나 범례 사이에도 간격을 둡니다.
- **규칙 C. 3D 객체가 자막 바나 상단 배너 밖으로 나감** (10, 17, 18번). 카메라가 멈추는 구도마다 3D 객체(바닥 평면, 계층 평면, 노드 포함)의 화면 투영이 자막 바 윗선(720p y 약 655) 위, 상단 배너 아래에 들어오게 합니다. 구도의 `zoom`을 낮추거나 `center`를 옮기거나 객체 크기를 줄입니다.

## 4. 푸시 전 자체 확인 (프레임 추출 스크립트)

`check_bounds`는 HUD 그룹만 검사해(`part2_collect_extract.py` 562, 1024행, `part3_decision.py` 666행 등) 3D 객체의 잘림과 가림을 잡지 못합니다(요청 36 1절 검사 보완의 남은 부분). 이번에 `main`에 프레임 추출 스크립트 `scripts/dev/extract_video_frames.py`를 넣었습니다. `origin/main`을 머지하면 쓸 수 있습니다. 스크립트는 수정하지 않고 실행만 합니다.

```bash
# PyAV(av)가 필요합니다. Manim을 설치한 가상환경의 python으로 실행합니다.
# 장면 전체를 1초 간격으로
python scripts/dev/extract_video_frames.py \
  <media_dir>/videos/part3_decision/720p30/Part3DecisionScene.mp4 <출력 폴더>/part3

# 카메라가 멈추는 구간을 0.25초 간격으로(예: 44~53초)
python scripts/dev/extract_video_frames.py \
  <media_dir>/videos/part3_decision/720p30/Part3DecisionScene.mp4 <출력 폴더>/part3_fine \
  --step 0.25 --start 44 --end 53
```

- 인자는 mp4 경로, 출력 폴더, `--step`(간격, 기본 1초), `--start`, `--end`(초)입니다. 파일 이름은 `t_050.0.jpg`처럼 시각입니다.
- 출력 폴더는 저장소 밖에 둡니다. 프레임을 커밋하지 않습니다.
- 렌더링은 `-qm`(1280x720)으로 하고, 네 장면을 순서대로 실행합니다(이번 검수도 같은 `--media_dir`에 한 장면씩 순서대로 렌더링했습니다).

장면마다 1초 간격 프레임 전체를 보고, 카메라가 멈추는 구간(`cam_move` 뒤의 `wait`)마다 그 구간의 프레임을 따로 뽑아 아래를 확인합니다.

4. 720p에서 한글 글자 높이(글자의 위 끝부터 아래 끝까지 픽셀 행 수, 확대해서 셈)가 11px 미만인 문구가 없는가.
