# 요청 24. 시안 4 전체 레이아웃 재구성: 기록에 접근하는 화면의 구성으로 (Antigravity 개발 에이전트용)

요청 22의 2단계와 3단계를 이 요청으로 바꿉니다. 요청 22의 1단계(PR 5번)에서 만든 것(문구 표, 회사 목록을 자료에서 읽기, 비교 범위 고르기, 여는 화면, 층의 경로)은 그대로 쓰고, 그 위에서 화면의 뼈대를 다시 짭니다.

## 사용자가 한 말 (2026-11-23, PR 5번을 직접 보고. 그대로)

> 현재 고객군과 시장, 가입 관문, 담보 비교는 여전히 시각적 직관성이 떨어지는 것 같아. 게임 화면에서 일반적인 옵션이나 아이템 관련 메뉴 말고 과거 기록이나 기억에 접근하는 UI들은 좀 더 기하학적이고 직관성이 강조된 내용이었는데 그런 것들은 적용하기 어렵나?

> 전반적인 레이아웃 재구성을 고려해봐야할 것 같은데

> 그리고 지식그래프 기반 탐색 화면은 어디에 있는거야?

Claude가 읽은 뜻입니다. 지금 화면은 옵션이나 장비 메뉴의 구성(글자 탭, 카드, 표, 옆 기둥)에 도형을 얹은 것입니다. 기록에 접근하는 화면은 다릅니다. 화면 전체가 도형 구성 하나이고, 그 도형이 곧 자료의 구조입니다. 한 장의 넓은 판에 "분류, 단위, 고른 것의 상세"가 왼쪽에서 오른쪽으로 함께 놓여서 어디를 보고 있는지 한눈에 보이고, 단위의 상태는 범례 없이 도형의 채움과 색으로 읽힙니다. 글은 고른 것 하나에만 붙습니다.

요청 22의 지시가 모자랐던 점도 적어 둡니다. 탭마다의 도형으로 적은 부채꼴 지도, 마름모 타일, 방사형은 기준 화면에 있는 도형이 아니라 Claude가 지어낸 제안이었고, "칸 안에 글자를 넣지 않는다"는 규칙 때문에 기호만 있는 칸이 생겨 뜻을 읽기 어려워졌습니다. 이번에는 기준 화면에 실제로 있는 구성과 도형을 가져옵니다.

## 새 뼈대 (모든 화면에 같게)

진행 추적기의 구성을 뼈대로 삼습니다. 1920x1080 기준입니다.

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 경로(작게)                                   지금 조건 한 줄      전체 값의 원 │
│ 큰 제목                                      [조건 바꾸기][비교 범위]         │
├──────────────────────────────────────────────────────────────────────────┤
│ (고리)고객군과 시장  (고리)가입 관문  (고리)담보 비교  (고리)영업 인사이트  (고리)관계 지도 │
├─────────────────┬──────────────────────────────┬─────────────────────────┤
│ 분류             │ 단위 (그 화면의 도형)           │ 고른 것의 상세            │
│ 묶음을 고른다     │ 단위를 고른다                  │ 이름, 판정, 문장, 근거     │
│ 약 22%           │ 약 44%                        │ 약 34%                  │
└─────────────────┴──────────────────────────────┴─────────────────────────┘
 [뒤로] [문장으로 보기] [요약 복사] [범례]
```

- 탭 줄을 하나로 합칩니다. 지금은 글자 탭 줄, 브리핑의 메달 다섯, 메달을 고른 뒤의 머리 띠가 같은 다섯 갈래를 세 번 보여 줍니다. 글자 탭 줄을 없애고, PR 5번의 머리 띠(고리와 이름)를 화면의 탭 줄로 올립니다. 고리 안의 수는 지금 브리핑 메달의 수(자료의 브리핑 값)입니다. 고른 탭은 짙은 면입니다.
- 브리핑은 탭이 아니라 처음 여는 상태입니다. 아무 탭도 고르지 않은 첫 화면에서는 고리 탭 다섯이 지금 메달처럼 크게 보이고(PR 5번의 첫 화면), 그 아래에 결론 다섯 줄이 번호를 단 목록으로 놓입니다. 고리를 고르면 탭 줄이 위로 줄어들고 세 구역의 판이 열립니다. 제목 옆 경로의 첫 마디를 누르면 처음 상태로 돌아갑니다.
- 근거 기둥을 판의 오른쪽 구역으로 합칩니다. 따로 떠 있는 옆 기둥을 없애고, 고른 것의 상세와 근거(원문 확인 표식, 식)를 오른쪽 구역 하나에 위에서 아래로 놓습니다. 아무것도 고르지 않았을 때는 그 화면의 결론 한 문장만 있습니다.
- 세 구역은 한 장의 판입니다. 구역 사이는 선이나 면의 짙기로만 나누고, 카드를 따로 띄우지 않습니다. 판 안에서 아래로 길게 쌓지 않습니다. 가운데 구역의 도형은 스크롤 없이 한 화면에 들어오게 하고, 넘치는 것은 왼쪽 분류를 바꿔서 봅니다.
- 조작은 왼쪽에서 오른쪽입니다. 분류를 고르면 가운데가 바뀌고, 단위를 고르면 오른쪽이 바뀝니다. 키보드는 화살표로 구역 안을 옮기고 Tab으로 구역을 넘어가며 Esc는 한 단계 왼쪽(위)으로 갑니다. 터치도 같습니다.
- 다섯째 탭으로 관계 지도(지식그래프 탐색)를 둡니다. 아래 "관계 지도"를 보세요.
