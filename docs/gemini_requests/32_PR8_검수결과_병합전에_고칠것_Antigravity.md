PR 8번(가지 `antigravity/console4-motion`, 요청 28의 움직임과 반응, 담보 비교의 두 층, 관계 지도와 요청 30의 PR 6번 검수 결함)을 검수한 결과입니다. 아직 `main`에 합치지 않았습니다. 지금 같은 가지에서 하고 있는 요청 31(담보 비교가 판정과 쌍 수를 자료에서 읽게 바꾸기)을 마친 다음에 이어서 고칠 목록입니다. 커밋 글에 이 문서의 번호(예 "요청 32의 1-2")를 적어 주세요.

PR 글에도 이 한계가 적혀 있지 않습니다. 원본은 `tab6.css` 68줄(`.gr-edges-svg`), 69, 71줄(`.gr-edge-g`, `.gr-edge-hit`의 `pointer-events:stroke`), 94줄(`.gr-cols-grid`)입니다. 노드 사이 골짜기에서는 엣지가 잡히게 합니다. 예를 들어 그래프 칸과 열에는 `pointer-events:none`을 주고 노드(`.gr-node-wrap`)와 단추에만 `auto`를 주거나, 엣지 층을 노드 층 위로 올리고 노드가 차지한 자리만 비웁니다. 끝내는 기준은 가리키면 칩이 뜨고(조준 표식과 같은 반응), 누르면 읽기 영역에 엣지 속성이 나오며, 엣지 위 표본점의 대부분(노드와 겹치지 않는 점 모두)에서 엣지가 잡히는 것입니다.
