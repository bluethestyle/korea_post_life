# 카본에게: 교차 확인과 정답셋 2차 요청

우체국보험 상품·청약 판단 지원 앱의 1단계(공시 문서 → 급부 추출·검증)를 만들고 있습니다. 지난번에 만들어 준 우체국 정답셋 85항목은 원문과 대조해 검수를 마쳤고, 그중 "보장금액·면책·감액" 30항목으로 추출 결과를 채점했습니다(전부 일치).

이번에는 세 가지를 부탁합니다. 첨부한 PDF만 근거로 삼고, 문서에 없는 값은 "문서에 없음"으로, 읽기 애매한 값은 "확인 필요"로 적어 주세요. 추정해서 채우지 않습니다. 모든 답에 근거 문서와 쪽수를 붙여 주세요.

## 과제 1. 추출 결과 교차 확인 (우체국 직전 개정판)

첨부: `우체국간편건강보험_2504_355_상품요약서.pdf`, `우체국간편건강보험_2504_325_상품요약서.pdf`, `추출결과_직전개정판.md`

`추출결과_직전개정판.md`는 배치가 두 요약서의 "보험금 지급사유"에서 뽑은 급부표입니다. 한 줄씩 원문 표와 대조해 주세요.

- 볼 칸: 지급액(만 원), 감액 기간(개월)과 감액 금액, 면책 날수(보장개시일 조건이 붙은 줄만 90일 등), 지급 한도
- 틀린 줄만 적습니다: 줄 번호, 틀린 칸, 원문 값, 쪽수
- 원문에는 있는데 표에 빠진 급부가 있으면 따로 적습니다
- 표의 "판정" 칸이 "검토"인 줄은 배치가 스스로 확신하지 못한 줄입니다. 이 줄은 맞아도 "맞음"이라고 적어 주세요

## 과제 2. 한화생명·삼성화재 정답셋

첨부: 한화생명 시그니처 H통합보험 무배당 상품요약서·사업방법서, 삼성화재 THE FIT 파트너(2610.1)(일반형) 상품요약서·사업방법서, 삼성화재 간편보험 새로고침(2607.5)(자동갱신형) 상품요약서·사업방법서

지난번 우체국 정답셋과 같은 형식으로 만듭니다.

| 칸 | 내용 |
| --- | --- |
| 번호 | 101번부터 |
| 영역 | 보장금액·면책·감액 / 가입조건 / 결합 제약 |
| 상품과종 | 상품명과 종(가입유형) |
| 특약급부명 | "특약명 · 급부명" |
| 질문 | 한 문장 |
| 정답 | 문서에 적힌 값 그대로. 없으면 "문서에 없음" |
| 근거문서 | 상품요약서 / 사업방법서 |
| 쪽수 | PDF 쪽 번호 |
| 근거문구 | 원문 20~60자 |

상품마다 아래 수량을 목표로 합니다(세 상품 합계 75항목 안팎).

- 보장금액·면책·감액 14항목: 암·뇌혈관·심장 진단, 수술, 입원, 치료비를 고루. 감액 기간이 1년이 아닌 급부, 면책 90일이 붙는 급부와 안 붙는 급부, 지급 한도(연간 횟수, 일수)가 있는 급부를 꼭 넣습니다
- 가입조건 6항목: 가입나이, 보험기간, 납입기간, 가입금액 한도
- 결합 제약 3항목: 의무 부가, 함께 가입할 수 없는 특약, 가입금액 연동
- "문서에 없음" 2항목: 그 문서에 실제로 없는 급부나 값을 묻는 문항

주의할 점

- 삼성화재 간편보험 새로고침 PDF는 1종(ZPB343050) 문서입니다. 이 문서가 다른 종(7종·8종 등)까지 함께 다루는지, 1종만 다루는지를 맨 앞에 적어 주세요
- 한화생명은 가입유형이 13개(간편가입형 0·1·2·3·4·5·10년, 일반가입형, 건강가입형 6~10년)입니다. 가입유형에 따라 값이 달라지는 문항은 어느 유형 기준인지 "상품과종"에 적습니다
- 보험료를 묻는 문항은 만들지 않습니다. 세 회사 요약서 모두 특약별 보험료가 없다는 것을 이미 확인했습니다
