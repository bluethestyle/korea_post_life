요청 37(화면 문구를 실무 용어로 바꾸는 요청, `docs/gemini_requests/37_시안4_화면문구를_실무용어로_Antigravity.md`)의 PR 10번(브랜치 `antigravity/console4-terms`, 커밋 `6f9c380`)을 검수했고, 머지하지 않았습니다. 머지를 막은 것은 1건(태블릿 폭에서 경로 잘림)입니다. 나머지 머지 기준은 모두 통과했습니다.

- 보이는 글자 검사(1920x1080, 1280x800, 380x800, 탭 여섯과 상태 전부)에서 지적한 말, 지금 용어, 내부 코드가 0건입니다.

이번에는 아래만 고쳐 같은 브랜치에 커밋을 더합니다. Antigravity 주간 한도가 적으므로 아래 범위 밖은 손대지 않습니다.

## 1. 머지 전에 고칠 것 (1건): 태블릿 폭에서 인수기준 비교 탭의 경로 마지막 칸이 잘림

- **화면**: 분석 화면 인수기준 비교 탭, 폭 1000~1279px(측정 1024x768, 1180x820, 터치 기기 설정). 제목 위 경로(`#lpath`, `<nav class="lpath">`, 이 폭에서 220px)의 마지막 칸 `.lp-cur`이 말줄임으로 잘립니다. 예: 항목을 선택하면 "전체 요약 > 인수기준 비교 > 가입나이 …"("가입나이 기준" 69px이 64px에 들어감).
- **원인**: 가운데 칸 탭 이름이 "가입 관문"(47px)에서 "인수기준 비교"(69px)로 길어졌습니다. CSS는 `proto_src/console4/style.css` 900~903행 `@media (min-width:1000px){ .lpath{flex-wrap:nowrap;overflow:hidden} .lpath .lp-cur{min-width:0;overflow:hidden;text-overflow:ellipsis;white-space:nowrap} }`입니다.
- **잰 값** (탭마다 기본 상태와 항목 선택 최대 12개, 경로 마지막 칸이 잘린 상태 수 / 전체 상태 수):

| 폭 | 탭 | main | PR |

- **재는 방법** (브라우저 콘솔): 인수기준 비교 탭에서 `#z-center .gtf-cell`을 하나씩 클릭한 뒤 아래를 실행해, 마지막 칸의 scrollWidth가 clientWidth+1보다 크면 잘린 것입니다.


- **근거**: 머지 기준 "문구가 길어지거나 짧아져 생긴 깨짐 없음, 다섯 해상도와 태블릿 1180x820에서 글자 잘림 0"에 걸립니다. 이 PR이 새로 만든 잘림입니다.

## 2. 함께 고칠 것 (2건)

1. 가입한도 표기: 문구 표 `proto_src/console4/core.js`의 아래 세 문구를 바꿉니다. 같은 화면의 다른 문구(415, 531, 790행)는 "가입한도"이고, 용어 대조표 65, 67번이 가입한도로 정했습니다.
