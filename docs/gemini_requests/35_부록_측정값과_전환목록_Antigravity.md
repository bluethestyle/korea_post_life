## 1. 측정 방법과 지표 정의

### 1.1 측정 절차

1. 트리거(클릭)를 페이지 안에서 실행합니다. 클릭 직전 상태를 한 번 기록하고, 이어서 `requestAnimationFrame`마다 700ms 동안(분류 이동은 2.2초) 추적 요소의 `getBoundingClientRect`, 조상까지 곱한 불투명도, `transform`, `clip-path`를 기록합니다. 본문 3절에 따라 시간을 늘린 전환은 명목 시간에 300ms를 더한 동안 기록합니다.
2. 프레임마다 `document.getAnimations()`를 훑어 CSS 애니메이션, CSS 트랜지션, 자바스크립트 애니메이션(WAAPI)의 이름, 시간, 이징을 모읍니다.
3. 조상의 `overflow`로 잘리는 요소(예: 가운데 영역 안의 화면 구역)는 잘린 상자로 비교합니다.
4. 전환마다 5회 반복해 중앙값을 적습니다. 33ms 넘는 프레임만은 3회 이상 실행한 가운데 가장 나쁜 값을 적습니다.
5. `clip-path`로 드러내는 전환은 `getBoundingClientRect`만으로 드러난 높이가 잡히지 않으므로 프레임마다의 `clip-path` inset 값을 함께 기록합니다.

이 측정을 `shoot.py`의 프레임 측정(요청 28 1절) 옆에 더하면 PR 글의 표를 채울 수 있습니다. Claude는 검수 때 저장소 밖의 측정 스크립트로 같은 지표를 다시 잽니다.

### 1.2 지표

| 지표 | 정의 |
| --- | --- |
| 명목 시간 | 전환 안에서 시작한 애니메이션의 `duration`(지연 포함 최대값)과 이징. 없으면 "없음" |
| 한 프레임 최대 이동 | 연속한 두 프레임에 모두 보이는(조상까지 곱한 불투명도 0.1 이상) 영역 요소의 위치나 크기가 한 프레임 사이에 바뀐 최대량(px). 패널, 패널에 밀리는 아래 콘텐츠, 모달 상자 같은 영역에 적용합니다. 링, 막대, 선택 표시(`#sel-glide`), 기준축 브리지 같은 도형은 "도형"으로 따로 적고 이 지표에 넣지 않습니다. `clip-path`로 드러내면 드러난 경계(inset 값)를 위치로 봅니다. 불투명도 0.1 미만인 프레임의 자리 변화는 세지 않습니다 |
| 레이아웃 점프 | `transform`을 뺀 레이아웃 위치나 크기가 한 프레임에 12px 이상 바뀌고, 그 요소의 총 변화 가운데 절반 이상이 그 프레임에 끝난 경우 |
| 컷 | 영역이 한 프레임에 나타나거나 사라지는 것. 나타나는 영역의 첫 프레임 불투명도가 0.9 이상이고 드러난 면적도 90% 이상이면 컷입니다. 사라질 때도 같습니다 |
| 100ms 진행률 | 클릭 직전 값에서 끝 값까지 가는 길 가운데 클릭 후 100ms 시점에 끝난 비율. 나타나는 요소의 시작 값은 높이 0, 불투명도 0입니다. 프레임 사이는 선형 보간합니다 |
| 닫기 애니메이션 있음 | 닫는 단계에서 애니메이션이 있고 값이 3프레임 이상에 걸쳐 바뀌는 것 |
| 33ms 넘는 프레임 | 보통 속도로 3회 이상 실행한 가운데 가장 나쁜 값(요청 28의 프레임 기준) |
| 패널 안 항목 | 조건 바꾸기 패널에서는 `.cond-body` 안의 조건 그룹 `.cg` 각각(`core.js` 1252~1253행). 불투명도는 그룹마다 재서 가장 높은 값을 적습니다 |
| "끔"에서 즉시 전환 | 클릭 다음 프레임에 끝 값이고, 그 전환의 애니메이션이 `document.getAnimations()`에 없음 |

### 1.3 측정할 때 주의

- 클릭은 `element.click()`으로 보냈습니다. 실제 포인터 입력의 `pointerdown` 효과(포커스 표시, 클릭 중 표시)는 재지 않았습니다. 큰 영역 전환은 `click`에서 시작하므로 영향이 없습니다.
- 5회 반복 가운데 일부에서 프레임 하나가 50ms로 늘어난 단계가 10개 있었습니다. 같은 서버에서 다른 점검이 함께 돌던 때(부하 5~7, 32코어)라 측정 환경의 지연으로 보입니다. 한 프레임 이동과 진행률은 5회 중앙값이라 영향을 받지 않습니다. 클릭에서 첫 `requestAnimationFrame`까지는 모든 단계에서 25ms 이내였습니다.
- 선택 표시(`#sel-glide`)가 움직이는 동안 문서 높이가 잠시 늘었다 돌아오는 현상(영업 인사이트의 내용 교체에서 최대 약 300px)은 도형 때문이라 이동량에서 뺐습니다.
