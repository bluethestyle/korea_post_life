# 화면 용어 대조표 (확정안)

화면(시안 4), 발표 자료, 제출 설명 문서, 사용검증 안내문에 쓰는 용어의 확정안입니다. 사용자 지시(2026-11-24, 직역체와 비실무 용어를 모두 보험 실무 용어로 바꾼다)에 따라 어제 초안(카본 제안 66행)에 머지 전 브랜치의 새 문구와 데이터 쪽 라벨을 더해 다시 수집하고, 행마다 확정안을 채웠습니다. 화면 코드와 데이터 라벨은 아직 고치지 않았습니다.

- 이 표의 확정안대로 진행합니다. 다른 의견이 있는 행만 번호로 알려 주시면 됩니다.
- "사용자 확인 필요"가 "예"인 8행(바로 아래 목록)은 화면 이름, 탭 이름처럼 실무자가 고를 말입니다. 후보 둘 가운데 고르거나 다른 말을 알려 주십시오. 답이 없으면 첫 후보로 진행합니다.
- 전체 203행: 교체 175행(사용자 확인 필요 8행 포함), 그대로 28행.

## 수집 범위와 기준

- 화면 코드: 머지 전 브랜치(PR 8번, 커밋 `ff38a67`)의 `proto_src/console4/`에서 `core.js`의 문구 표 `COPY`(294개 키), `tab1.js`부터 `tab6.js`까지(`tab4.js`는 원본 `tab4.src.js`로 봄), `tpl.html`.
- 데이터: `src/postlife/site/`의 `sales.py`, `console4.py`, `insights.py`, `relations.py`와 `proto_src/graph/build_data.py`가 만들어 `proto_src/console4/*.json`, `proto_src/graph/graph.json`에 싣는 값.
- 화면에 실제로 보이는 문자열만 봤습니다. 코드 식별자, CSS 클래스, 자료의 키 이름은 뺐습니다. 값을 채워 넣는 문장은 템플릿 단위로 봤고, 같은 말이 여러 문장에 들어 있으면 그 말을 한 행으로 적었습니다.
- 상품명, 특약명, 급부명처럼 공시 문서에서 옮긴 글자와 시장 동향의 보도 요약 인용문은 대상이 아닙니다.
- "공시 문서 표기 확인"은 저장소 밖(`local/`)에 받아 둔 공시 문서 41개(우체국, 생명보험사, 손해보험사의 상품요약서와 사업방법서)의 글자에서 그 표기를 찾았다는 뜻입니다. 원문 문장은 옮기지 않았습니다.
- "프로젝트 지침의 교체표"는 `CLAUDE.md` 용어 절의 교체표, "메인 세션 권고"는 이번 작업 지시에 들어 있던 기본값입니다.
- 길이: 탭, 배지, 칩, 필터 버튼, 표 머리처럼 좁은 자리에 들어가는 말은 지금 글자 수의 1.3배 이내로 맞추고, 넘으면 "짧은 표기"를 함께 정했습니다. 더 짧은 실무 표기가 없어 기준을 조금 넘는 말은 53번(통원수술, 1.33배) 하나입니다.
- 쓰이는 곳: "화면 코드"는 Antigravity가 고칠 화면 문구, "데이터"는 Claude가 고칠 라벨과 문장, "둘 다"는 양쪽에 같은 말이 있는 경우입니다.
- 한 개념에 한 용어: 같은 대상을 화면마다 다르게 부르던 곳을 하나로 맞췄습니다(9번과 10번, 25번, 83번, 98번, 104번, 139번, 153번).
- 어제 표에 있던 "분석 단계", "메달", "앞세울 것", "물어올 것", "원문 대조"와 근거 영역의 옛 이름은 지금 화면에 보이지 않아(코드 주석과 자료 키에만 남음) 표에서 뺐습니다.
