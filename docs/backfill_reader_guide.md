# 초기 적재 판독 지시문

이 지시문은 초기 적재에서 상품요약서의 급부 표를 읽는 판독자(Claude 에이전트)가 묶음 하나를 받아 값을 내는 방법을 적은 것이다. 같은 묶음을 판독자 둘이 따로 읽고, 코드가 두 판독을 견주고 원문 글자와 대조한다. 두 판독이 같고 기계 검사를 통과한 줄만 확정되므로, 확신이 없으면 지어내지 말고 "모름"으로 둔다.

견주는 코드는 `src/postlife/extract/reader_rows.py`, 묶음을 만드는 도구는 `scripts/split_pieces.py`, 견주는 도구는 `scripts/compare_readers.py`다.

회사별 보충: 묶음 파일에 `읽을종`이 있는 회사(삼성생명)는 `docs/backfill_reader_guide_samsunglife.md`를, KB라이프생명 묶음(이름 앞머리 `331000106`, `335000106`)은 `docs/backfill_reader_guide_kblife.md`를, 묶음 파일에 `읽을단계`가 있는 교보생명 묶음(이름 앞머리 `1001031`, `1001042`)은 `docs/backfill_reader_guide_kyobo.md`를, 현대해상 묶음(이름 앞머리 `131A`, `11F0`)은 `docs/backfill_reader_guide_hyundai.md`를 함께 읽는다. 이 지시문의 칸과 허용값은 그대로이고, 보충은 그 회사 문서에서 조심할 곳과 값 고르는 법만 더한다. 메리츠화재 묶음은 이 지시문만 읽는다.

## 1. 받는 것

- 묶음 파일(JSON) 하나. 형식은 `판독묶음/1`이다.
  - `묶음`: 묶음 이름. 예: `6AFLT_B03`
  - `PDF`: 판독자가 열어 볼 상품요약서 PDF의 경로. `쪽`은 이 PDF의 쪽 번호와 같다.
  - `조각`: 특약(조각) 목록. 조각마다 `조각번호`, `쪽`(첫쪽과 끝쪽), `특약명`, 있으면 `특약명들`, `형`, `주석`, 그리고 `세부보장` 목록.
  - `특약명들`: 본형, 추가형, 갱신형처럼 이름만 다른 특약 여럿이 표의 한 칸을 함께 쓸 때 그 이름들. 이때 `특약명`과 세부보장명은 그 이름들을 "/"로 이은 꼴이다. 급부는 하나이고 값도 한 벌이다.
  - 세부보장마다 `번호`(예: `R012-3`), `쪽`, `세부보장명`, `지급사유`, `지급금액`, 그리고 한 조각 안에 이름이 같은 세부보장이 여럿이면 `"이름같은줄": true`. 지급사유와 지급금액은 표 읽기 코드가 PDF에서 뽑은 칸의 글자다.
  - 한 표 안에 종별 값이 함께 있는 요약서의 묶음에만: 묶음의 `읽을종`(예: `2종`), 조각과 세부보장의 `적용범위`(그 특약이나 줄이 걸리는 종). 회사별 보충을 본다.
- 판독 파일을 쓸 폴더와 판독자 이름(예: `sonnet`, `opus`), 꼴 검사를 돌릴 도구 폴더와 파이썬 경로. 의뢰문에 적혀 있다.

## 2. 내는 것

판독 파일 하나를 `<폴더>/<묶음>.<판독자>.json`으로 쓴다(예: `6AFLT_B03.sonnet.json`). 묶음의 세부보장마다 한 줄씩, 빠짐없이, 묶음에 적힌 차례대로 낸다.

```json
{
  "형식": "판독값/1",
  "묶음": "6AFLT_B03",
  "판독자": "sonnet",
  "값": [
    {"번호": "R139-1", "쪽": 105, "꼴": "가입금액비율", "지급률": 100, "...": "..."}
  ]
}
```

다 쓴 뒤에 꼴 검사를 돌려 "꼴 문제 없음"이 나오는지 본다. 이 검사는 칸 이름과 허용값, 빠진 번호, 이름이 같은 줄의 대상만 본다. `<도구 폴더>`와 `<파이썬>`은 의뢰문에 적힌 경로다(리포의 `src/postlife`와 `scripts/compare_readers.py`를 복사해 둔 폴더).

```bash
PYTHONPATH=<도구 폴더> <파이썬> <도구 폴더>/compare_readers.py <묶음 파일> --check <판독 파일>
```

## 3. 읽는 순서

1. 묶음 파일을 연다. 세부보장 번호와 이름, 쪽을 확인한다.
2. 세부보장마다 그 쪽의 PDF를 직접 연다(Read 도구에 `pages`로 쪽 번호를 준다. 예: `pages: "105"`). 한 번에 몇 쪽씩 열어도 된다.
3. 값은 PDF에서 읽는다. 묶음의 지급사유와 지급금액 글자는 그 줄을 찾는 길잡이로만 쓴다. 표가 글자로 풀리면서 옆 칸 글자가 섞이거나, 위첨자 표시가 줄 사이로 옮겨 가거나, 칸 안의 작은 표가 한 줄로 뭉개진 곳이 있다. 특약 끝의 ※ 풀이 행은 그 특약의 모든 줄 지급사유 끝에 붙어 있다(5.2절).
4. 아래 4절의 칸을 채운다. 원문 문장을 옮겨 적지 않는다. 숫자, 허용값, 짧은 낱말만 적는다.
5. 다른 판독자의 파일을 보지 않는다. 같은 묶음을 다시 읽어 고칠 때도 자기 파일만 고친다.
6. 내기 전에 줄마다 두 가지를 스스로 확인한다. 두 판독자가 같은 방식으로 빠뜨리면 견줌으로는 잡히지 않는다.
   - 빈 칸이 맞는가: 지급사유 본문과 지급금액 칸에 감액을 가리키는 말("1년 미만 50%", "경과시점 전일 이전", "감액 지급")이 있는데 `감액`을 비웠거나, 한도를 가리키는 말("1회한", "1회에 한하여", "30일 한도", "최초 1회", "연간 3회")이 있는데 `한도`를 비웠거나, 이름이 붙은 보장개시일을 가리키는데 `면책일수`가 0이면 다시 본다. "단, 가나암은 1년 미만 50%"처럼 단서로 붙은 감액도 감액이다(`감액대상`, 4.6절).
   - 이름의 표식과 값이 맞는가: 특약명이나 세부보장명에 "연간1회한", "최초1회한", "180일한도"가 있으면 `한도`에, "감액기간미적용", "감액및면책기간미적용"이 있으면 `감액`과 `면책일수`에, "일당"이 있으면 `지급단위`에 그 표식이 맞게 들어갔는지 본다. 이름과 칸의 글이 서로 다르면(이름은 "연간30회한", 칸은 "연간 30일 한도") 칸을 따른다. 코드가 이 둘을 다시 검사하고, 걸린 줄은 메인 세션이 본다.

하지 않을 것

- 특약 이름과 세부보장 이름을 고치거나 새로 짓지 않는다. 이름은 칸이 아니다. 번호로만 가리킨다. 이름이 같은 줄을 가르는 것은 `대상` 칸(4.11절)이다.
- 묶음에 없는 번호를 더하지 않는다. 한 줄에 대상이 여럿 보여도 줄을 나누지 않는다.
- 계산해서 만든 값을 원문에 적힌 값처럼 적지 않는다. 예외는 4.6절의 감액 값(받는 몫)뿐이다.

## 4. 칸과 허용값

| 칸 | 값 | 비울 때 |
| --- | --- | --- |
| `번호` | 묶음의 세부보장 번호 그대로 | 비우지 않는다 |
| `쪽` | 값을 읽은 PDF 쪽(정수) | 비우지 않는다 |
| `꼴` | `가입금액비율`, `금액`, `행없음`, `모름` | 비우지 않는다 |
| `행없음사유` | 4.2절의 목록 | 꼴이 행없음이 아니면 `""` |
| `대상` | `"이름같은줄": true`인 줄에만: 그 줄의 지급사유에 적힌 대상 낱말(30자 이하, 4.11절) | `""` |
| `지급률` | 감액이 끝난 뒤 가입금액의 몇 %인가(숫자) | 가입금액비율이 아니면 `null` |
| `기준가입금액만원`, `지급액만원` | 표에 적힌 기준 가입금액과 그때의 지급액(만 원) | 금액이 아니면 `null` |
| `지급률곱` | 가입금액에 (장해)지급률을 곱해 주면 `true` | `false` |
| `지급단위` | `""`, `1일당`, `1회당`, `1사고당` | `""`(한 번에 주는 돈) |
| `감액` | `[{"기간", "단위", "값", "값기준"}]` 많아야 둘 | `[]` |
| `감액대상` | 감액이 일부 경우에만 걸리면 그 경우를 가리키는 원문 낱말 | `""` |
| `감액예외` | `[{"대상", "자리"}]` 감액하지 않는 경우 | `[]` |
| `면책일수` | 보장개시일까지의 날수(정수) | `0`(계약일부터 보장) |
| `보장개시일` | 그 보장개시일의 이름(원문 낱말) | `""` |
| `면책근거쪽` | 이름과 날수가 함께 적힌 쪽(4.7절) | `null` |
| `한도` | `[{"앞말", "수", "단위"}]` | `[]` |
| `주의` | 4.9절의 목록 | `[]` |
| `모름` | `[{"칸", "이유"}]` 읽지 못한 칸과 짧은 이유(80자 이하) | `[]` |

꼴이 `행없음`이면 `행없음사유`와 함께 `면책일수`, `보장개시일`, `면책근거쪽`, `한도`도 채운다. 행은 만들지 않아도 이 정보는 남기고, 두 판독이 이 칸들까지 같아야 확정된다. 나머지 칸(지급률, 감액 따위)은 비워도 된다. 꼴이 `모름`이면 `모름`에 이유를 하나 이상 적는다.

### 4.1 꼴 고르기

- `가입금액비율`: 지급액이 가입금액의 몇 %로 정해지는 줄. 지급금액 칸이 "가입금액", "가입금액의 20%", "1일당 가입금액", "가입금액 × 지급률"이면 여기다. 감액이 있어도, 1일당이어도, 한도가 붙어도 여기다.
- `금액`: 가입금액과 상관없이 정해진 돈을 주는 줄. 표에 기준 가입금액과 지급액이 함께 적혀 있어야 한다.
- `행없음`: 지급률 하나, 감액 구간 둘, 면책 하나로 담을 수 없는 줄. 4.2절의 사유 가운데 하나를 고른다.
- `모름`: PDF를 보고도 꼴을 정할 수 없는 줄.

### 4.2 행없음사유

| 사유 | 이런 줄 |
| --- | --- |
| `가입금액구간별금액표` | 칸 안의 작은 표가 가입금액 구간(예: 1천만원, 2천만원 열)마다 다른 금액을 적는다. 항목 행과 가입금액 구간 열이 겹친 표(항목마다, 구간마다 금액이 다른 표)도 여기다 |
| `항목별금액표` | 치료 항목마다 금액이나 지급률이 다르고 가입금액 구간 열은 없다 |
| `회차별지급률` | 1회차 100%, 2회차 125%처럼 회차마다 지급률이 다르다 |
| `경과기간별지급률` | 진단 후 경과 연도별로, 또는 계약일부터 경과시점별로 지급률이 달라진다. 계약일부터 1년 전과 후로 열이 갈리는 체증표도 여기다(5.1절 지어낸 예 5) |
| `등급별지급률` | 점수, 등급, 중증도마다 지급률이 다르다 |
| `조건별지급률` | 사용 금액이나 시간 같은 조건마다 지급률이 다르다 |
| `치료차수별지급률` | 최초 치료와 두 번째 치료부터의 지급률이 다르다 |
| `약물종류개수별` | 연간 약물 종류 개수에 따라 지급이 갈린다 |
| `종구분별가입금액` | 1-5종, 1-7종처럼 종마다 가입금액이 따로 있다 |
| `단위당단가` | 흉터 1cm당 얼마처럼 길이, 면적 같은 단위마다 금액이 붙는다 |
| `조문별한도` | 벌금처럼 법 조문이나 위반 종류마다 한도 금액이 다르다 |
| `실제손해액` | 실제 비용, 손해액, 합의금을 한도 안에서 준다 |
| `정기분할지급` | 매월 몇 년간처럼 나눠 준다 |
| `현물급부` | 간병인 지원처럼 돈이 아닌 급부만 있다 |
| `그밖` | 위에 들지 않는데 행으로 담을 수 없는 꼴. 메인 세션이 원문을 보고 정한다 |

### 4.3 지급률

감액이 끝난 뒤의 지급률이다. "가입금액"만 적혀 있으면 `100`, "가입금액의 20%"면 `20`, "가입금액 × 25%"면 `25`다. 칸 안에 1년 이전 지급률이 함께 적혀 있어도 지급률 칸에는 1년 이후 값을 적고, 1년 이전 값은 감액에 적는다.

### 4.4 금액

`금액` 꼴만 쓴다. "기준 가입금액 1,000만원, 지급액 300만원"이면 `기준가입금액만원: 1000`, `지급액만원: 300`. 원 단위로 적힌 금액은 만 원으로 바꾼다(5천원은 `0.5`).

### 4.5 지급률곱, 지급단위

- 지급금액 칸이 "가입금액 × 지급률"처럼 장해지급률을 곱하면 `지급률곱: true`, `지급률: 100`.
- 지급단위는 지급금액 칸을 먼저 본다. 지급금액 칸에 단위가 있으면 그 칸을 따른다. 지급금액 칸에 단위가 없을 때만 지급사유 칸의 "1회당", "1일당"을 따른다. 예: 지급사유에 "통원 1회당 지급", 지급금액에 "1일당 가입금액"이면 `1일당`.
- "1일당 가입금액", "입원 1일당"이면 `1일당`, "1회 통원당", "수술 1회당"이면 `1회당`, "1사고당 가입금액"이면 `1사고당`.
- "1회 입원당 180일 한도"의 "1회 입원당"은 지급단위가 아니라 한도의 앞말이다(4.8절).
- 한도가 일수인데(지어낸 예: "가나병으로 입원 시 (1회 입원당 120일 한도)") 지급금액 칸과 지급사유 칸 어디에도 "1일당"이 없으면, 날마다 주는지 한 번에 주는지 원문이 말하지 않는 것이다. `지급단위`는 비우고 `모름`에 `지급단위`를 적는다. 그래야 두 판독이 같아도 확정되지 않고 메인 세션이 원문을 본다.

### 4.6 감액

계약일(가입일)부터 일정 기간 안에 덜 주는 구간이다. 구간마다 아래 넷을 적는다. 짧은 기간을 먼저 적는다.

- `기간`, `단위`: 구간이 끝나는 기간. "가입 후 1년이 지나기 전"이면 `1`, `년`. "가입 후 90일이 지나기 전"이면 `90`, `일`.
- `값`, `값기준`: 그 구간에 받는 몫.
  - "가입금액의 50%", "가입금액 × 50%"처럼 가입금액에 대한 비율이면 그 숫자와 `가입금액`.
  - "지급금액의 50%", "가입금액 × 지급률 × 50%"처럼 보험금 전체에 대한 비율이면 그 숫자와 `보험금`.
  - "50% 감액 지급", "75% 감액"처럼 덜 주는 몫으로 적혀 있으면 받는 몫(100에서 뺀 값)과 `보험금`. 75% 감액이면 `25`.
  - 금액 꼴에서 "1년 미만 150만원"처럼 돈으로 적혀 있으면 만 원 단위 금액과 `만원`.
- 지급률이 20%이고 1년 이전이 "가입금액의 10%"면 `값: 10`, `값기준: 가입금액`이다. 코드가 10 ÷ 20으로 받는 비율 0.5를 계산한다.

감액이 일부 경우에만 걸리면 `감액대상`에 그 경우를 가리키는 원문 낱말을 적는다. 예: "가가암은 1년 이전 50%"면 `감액대상: "가가암"`. 감액하지 않는 경우가 따로 적혀 있으면 `감액예외`에 대상 낱말과 그 문구가 있는 자리를 적는다. 예: 표 아래 "주1) 가나 사고로 생긴 경우에는 감액하지 않음"이 이 줄에 걸리면 `{"대상": "가나 사고", "자리": "주석"}`. 자리는 `지급사유`, `지급금액`, `주석` 가운데 하나다. 코드는 그 자리에서 낱말이 든 문구를 찾아 시트에 옮긴다. 낱말은 원문 글자 그대로 짧게 적는다.

### 4.7 면책일수, 보장개시일, 면책근거쪽

- 지급사유가 "가나보장개시일 이후"처럼 이름이 붙은 보장개시일을 조건으로 삼으면, 그 보장개시일이 계약일부터 며칠 뒤인지 적는다. "90일이 지난 다음날"이면 `90`, "1년이 지난 다음날"이면 `365`.
- `보장개시일`에는 그 이름을 원문 글자 그대로 적는다. 예: `"가나보장개시일"`.
- "보험기간 중"으로 시작하거나 이름 없는 "보장개시일 이후"면 `0`과 `""`.
- 그 줄에 면책이 걸리는지는 지급사유 본문으로 판단한다. 본문이 "가나보장개시일 이후"를 조건으로 삼으면 면책이 있고, "보험기간 중"이면 없다. 지급사유 끝에 붙은 ※ 풀이 문장(5.2절)은 그 특약의 모든 줄에 붙어 있으므로, 그 문장이 있다는 것만으로 면책을 적지 않는다.
- 날수를 정한 문장이 그 줄의 칸이나 그 특약의 주석에 없고 PDF의 다른 곳에 있으면, 그 보장개시일의 이름(또는 그 줄의 보장명)과 날수가 함께 적힌 쪽 번호를 `면책근거쪽`에 적는다. 코드가 그 쪽의 글자에서 이름과 날수의 짝을 확인한다. 이런 쪽이 된다.
  - 정의 문장: "가나보장개시일은 계약일부터 90일이 지난 다음날"이 적힌 쪽(쪽 아래의 ※ 줄, 앞뒤 쪽).
  - 나열 문장: 보장개시일 이름 여럿을 한 문장에 늘어놓고 날수를 정한 쪽(5.6절). 그 이름이 그 문장에 들어 있어야 한다.
  - 면책기간 표: 보장명마다 면책기간 칸에 날수를 적은 표가 있는 쪽(5.6절). 그 줄의 보장명이 표에 있고 바로 옆 칸에 날수가 있어야 한다.
  - 보장개시일 이름만 나오고 날수가 없는 쪽(지급사유가 이어지는 쪽 따위)은 면책근거쪽이 아니다.
- 날수를 정한 쪽을 찾지 못하면 `모름` 목록에 `면책일수` 칸을 적는다(`{"칸": "면책일수", "이유": "…"}`). `면책일수` 칸은 기본값 `0`으로 두고 "모름"이라는 글자를 넣지 않는다(4.10절).
- 나이에 따라 보장개시일이 다르면(예: 15세 미만은 계약일) 15세 이상의 날수를 적고 `주의`에 `나이별보장개시일`을 넣는다.

### 4.8 한도

지급 횟수나 일수의 한도마다 `{"앞말", "수", "단위"}` 하나다.

- `앞말`: `최초`, `연간`, `월간`, `1회입원당`, `1사고당`, `보험기간`, `없음`. "최초 1회한"은 `최초`, "연간 3회한"은 `연간`, "1회 입원당 180일 한도"는 `1회입원당`, "120일 한도"처럼 앞말이 없으면 `없음`.
- `수`: 정수. `단위`: `회` 또는 `일`.
- "각각 최초 1회한"의 "각각"은 적지 않는다. 코드가 원문 구절을 자를 때 함께 자른다.
- 한정어("동일한 가나병당", "신체부위별", "치료구분별 각각"처럼 한도 앞에 붙은 말)는 추출 모델이 적지 않고 코드가 원문에서 함께 자른다.
- 한도는 지급사유, 지급금액, 세부보장명, 그 특약의 주석 어디에 적혀 있어도 된다. 코드는 앞말, 수, 단위가 맞는 구절을 그 글자에서 찾는다.
- "연간 총 지급액은 가입금액을 한도로 함"처럼 돈의 한도는 적지 않는다. 그런 줄은 대개 행없음이다.
- "연1회한", "연 1회"도 앞말은 `연간`이다.
- 앞말이 없는 "1회에 한함", "가나병, 다라병 각각 1회의 진단에 한함"(지어낸 예)은 앞말 `없음`이다. 횟수가 1이라고 `최초`로 읽지 않는다.
- 연간 한도에 총 횟수나 지급기간의 상한이 함께 붙으면(지어낸 예: "연 1회(최대 5회)", "진단 뒤 5년 안에서 연간 1회한(합계 5회까지)") 한도에는 `연간` 1회 하나만 적는다. 총 횟수와 기간의 상한은 한도 칸에 담을 수 없으므로 `주의`에 `그밖`을 반드시 넣는다(4.9절). 한 판독만 넣으면 줄이 갈리고, 둘 다 빼면 상한이 사라진 채 확정된다.
- "1일 1회한"은 한도에 적지 않는다(앞말에 1일이 없다).
- "통원 1일당 1회, 연간 20일 한도"(지어낸 예)는 `지급단위: "1일당"`에 한도 `연간` 20일이다. "1일당 1회"를 `1회당`으로 읽지 않는다.

### 4.9 주의

행은 만들되 시트가 담지 못하는 정보다. 해당하는 것을 모두 넣는다.

| 값 | 이럴 때 |
| --- | --- |
| `나이별보장개시일` | 나이에 따라 보장개시일이 다르다 |
| `면책예외` | 일부 경우에는 면책기간이 없다. 한 줄에 면책이 있는 대상과 없는 대상이 함께 나오면 넣는다. 예: "가나보장개시일 이후 가나암으로 진단되거나 보험기간 중 다라암으로 진단된 경우"(가나암은 면책, 다라암은 면책 없음). 이때 `면책일수`와 `보장개시일`에는 면책이 걸리는 대상(가나암)의 날수와 이름을 적는다. 상해는 면책기간이 없고 질병만 있는 줄도 여기다 |
| `세부보장여럿묶임` | 서로 다른 급부가 한 줄에 묶여 값이 대상별로 달라질 때만 넣는다(지어낸 예: 세부보장명이 "가나진단비다라진단비"이고 가나와 다라의 가입금액이 따로 있다). 같은 급부의 본형, 추가형, 갱신형 특약 이름을 "/"로 이은 줄(`특약명들`이 있는 조각, 값이 한 벌)에는 넣지 않는다. 이 값이 있는 줄은 확정되지 않고 메인 세션이 본다 |
| `현물선택` | 돈 대신 현물(간병인 지원)을 고를 수 있다 |
| `지급기간중감액` | 감액이 보험금 지급기간 동안 걸린다 |
| `그밖` | 위에 들지 않는 것. 연간 한도에 붙은 총 횟수나 지급기간의 상한(4.8절)도 여기다. 이 값이 있는 줄은 확정되지 않고 메인 세션이 본다 |

### 4.10 모름

어느 칸을 읽지 못했으면 `모름`에 `{"칸": "<칸 이름>", "이유": "<80자 이하>"}`를 적고 그 칸은 기본값으로 둔다. 이유에는 원문 문장을 옮기지 않고 무엇이 막혔는지만 적는다. 예: `"날수를 정한 문장을 찾지 못함"`, `"칸이 겹쳐 지급률이 둘로 읽힘"`. 모름은 틀린 값보다 낫다. 모름인 줄은 메인 세션이 원문을 보고 정한다.

### 4.11 대상

묶음에 `"이름같은줄": true`가 붙은 줄(한 조각 안에 세부보장명이 같은 줄이 여럿)에만 적는다. 그 줄의 지급사유에 적힌 대상 낱말을 원문 그대로, 30자 이하로 적는다. 급부명은 "세부보장명(대상)"이 되고(삼성화재 적재의 대상별 줄과 같은 규칙), 급부ID도 이 이름으로 만든다.

- 같은 이름의 줄끼리 서로 다른 대상을 적어야 한다. 대상이 비었거나 다른 줄과 같으면 확정되지 않는다.
- 대상은 줄을 서로 가르는 낱말이다. 진단명이 다르면 진단명을, 진단명이 같고 수술 종류가 다르면 수술 종류를 적는다.
- 대상 낱말 바로 뒤에 붙은 괄호는 제외 단서가 든 것이어도 원문 그대로 대상에 넣는다. 지어낸 예: 지급사유가 "가암(나암 제외)으로 진단 확정된 경우"면 대상은 `가암(나암 제외)`이고 `가암`이 아니다. 이미 시트에 있는 삼성화재와 메리츠화재의 급부 이름이 이 꼴이라 급부ID 규칙이 맞는다. 단서까지 넣으면 30자가 넘는 줄은 단서를 자르지 말고, 대상에 괄호 앞의 낱말만 적은 뒤 `모름`에 `대상`을 적는다(이유 예: `"제외 단서까지 30자를 넘음"`). 메인 세션이 정한다.
- "…으로 진단 확정"이 아니라 "가암(나암 제외) 진단 확정 후"처럼 "으로"가 없는 문장도 "진단 확정" 바로 앞의 질병 이름(뒤에 붙은 괄호 포함)을 적는다. "진단 확정"이라는 말이 없는 문장은 그 줄을 다른 줄과 가르는 낱말(수술 종류, 조건 낱말 따위)을 적는다.
- 낫표(「」)와 따옴표는 적지 않아도 된다. 빈칸, 쉼표, 가운뎃점, 괄호 글자, "또는", "및"의 차이는 코드가 같은 것으로 본다. 예: `다라암 또는 마바암`과 `다라암, 마바암`은 같다. 견줌은 괄호 글자만 떼고 괄호 안의 글은 남겨서 견준다. 그래서 `가암(나암 제외)`와 `가암 나암 제외`는 같지만, `가암(나암 제외)`와 `가암`은 다르다. 한 판독만 단서를 떼면 그 줄은 갈린다. 지급사유에서 대상 바로 뒤에 제외 단서 괄호가 이어지는데 대상에 그 단서가 없으면 기계 검사가 표시를 낸다.
- `"이름같은줄"`이 없는 줄에는 대상을 적지 않는다.
- 행없음 줄(가입금액 구간별 금액표 따위)은 급부 행을 만들지 않고, 두 판독의 대상을 서로 견주지도 않는다. 그 줄의 대상은 어느 낱말을 고를지 오래 고민하지 않아도 된다. 같은 이름의 줄끼리 서로 다르게만 적는다(비우거나 겹치면 꼴 검사가 막는다). 다만 행없음 줄도 사유와 면책일수, 보장개시일, 한도는 견준다(7절). 한도는 행없음 줄에서도 읽는다.

지어낸 예

| 보장명 | 지급사유 | 지급금액 |
| --- | --- | --- |
| 가나치료비 | 가나보장개시일 이후 「가나암」으로 진단되고 치료를 받은 경우 | 가입금액 |
| 가나치료비 | 보험기간 중 「다라암」 또는 「마바암」으로 진단되고 치료를 받은 경우 | 가입금액의 20% |

`{"번호": "R001-1", "대상": "가나암", ...}`, `{"번호": "R001-2", "대상": "다라암 또는 마바암", ...}`. 급부명은 "가나치료비(가나암)", "가나치료비(다라암 또는 마바암)"이 된다.

## 5. 표에서 조심할 곳

### 5.1 칸 안의 작은 표

지급사유 칸 안에 작은 표가 있으면 묶음 글자에는 `· 왼쪽 칸: 나머지 칸` 줄로 풀려 있다. 머리가 두 줄인 표는 머리 글자가 섞여 읽히기도 한다. 반드시 PDF에서 표를 보고 꼴을 정한다.

지어낸 예 1. 가입금액 구간별 금액표

| 치료 항목 | 가입금액 1천만원 | 가입금액 2천만원 | 가입금액 3천만원 |
| --- | --- | --- | --- |
| 가나 검사 | 5만원 | 5만원 | 10만원 |
| 다라 수술 | 300만원 | 600만원 | 900만원 |

항목 행과 가입금액 구간 열이 겹쳐 항목마다, 구간마다 금액이 다르다. `꼴: "행없음"`, `행없음사유: "가입금액구간별금액표"`.

지어낸 예 2. 회차별 지급률

| 구분 | 지급금액 |
| --- | --- |
| 1회차 | 가입금액의 100% |
| 2회차 | 가입금액의 130% |
| 3회차 이후 | 가입금액의 160% |

`꼴: "행없음"`, `행없음사유: "회차별지급률"`.

지어낸 예 3. 종마다 가입금액이 따로 있는 표

| 구분 | 지급금액 |
| --- | --- |
| 1종 수술 | 1종 수술비 가입금액 |
| 2종 수술 | 2종 수술비 가입금액 |

`꼴: "행없음"`, `행없음사유: "종구분별가입금액"`.

지어낸 예 4. 작은 표가 보장 대상만 나열하고 지급액은 모두 같다

| 대상 | 지급금액 |
| --- | --- |
| 가나병 수술 | 가입금액 |
| 다라병 수술 | 가입금액 |

대상별 지급이 같으면 `가입금액비율`, `지급률: 100`이다. 값이 한 벌이므로 `세부보장여럿묶임`을 넣지 않는다.

지어낸 예 5. 계약일부터 1년 전과 후로 열이 갈리는 체증표

| 구분 | 계약일부터 1년 이전 | 계약일부터 1년 이후 |
| --- | --- | --- |
| 진단 후 1차연도 | 가입금액의 50% | 가입금액의 100% |
| 진단 후 2차연도 | 가입금액의 60% | 가입금액의 120% |
| 진단 후 3차연도 이후 | 가입금액의 70% | 가입금액의 140% |

연도마다 지급률이 늘고, 그것이 다시 1년 전과 후로 갈린다. 지급률 하나와 감액 구간으로 담을 수 없다. `꼴: "행없음"`, `행없음사유: "경과기간별지급률"`.

지어낸 예 6. 단위당 단가

| 부위 | 지급금액 |
| --- | --- |
| 가나 부위 | 1cm당 10만원 |
| 다라 부위 | 1cm당 5만원 |

`꼴: "행없음"`, `행없음사유: "단위당단가"`.

지어낸 예 7. 조문별 한도

| 구분 | 지급금액 |
| --- | --- |
| 가나법 위반 벌금 | 실제 벌금액(2,000만원 한도) |
| 다라법 위반 벌금 | 실제 벌금액(500만원 한도) |

`꼴: "행없음"`, `행없음사유: "조문별한도"`.

### 5.2 위첨자 표시와 붙은 ※ 풀이

"가나보장개시일※" 같은 위첨자 ※는 그 낱말의 뜻을 표 아래나 쪽 아래에서 풀어 준다는 표시다. 묶음 글자에서는 줄 높이가 달라 지급사유 첫머리나 줄 사이로 옮겨 가 있기도 하다. PDF에서 ※가 붙은 낱말을 찾고, 그 풀이 문장에서 날수를 읽는다. 풀이가 다른 쪽에 있으면 `면책근거쪽`에 그 쪽을 적는다.

표 읽기 코드는 특약 끝의 "※ 가나보장개시일은 …일이 지난 다음날" 같은 풀이 행을 그 특약의 모든 줄 지급사유 끝에 붙인다. 그래서 면책이 없는 줄(보험기간 중 다라암으로 진단된 경우 따위)에도 날수 문장이 보인다. ※가 그 줄에 걸리는지는 지급사유 본문(보장개시일 이후인지, 보험기간 중인지)으로 판단한다.

### 5.3 주석(주1, 주2)

지급금액 칸에 "주1)" 같은 표시가 있으면 표 아래나 그 형 구간이 끝나는 쪽에 그 풀이가 있다. 묶음의 조각에 `주석`이 붙어 있으면 그 글이다. 붙어 있지 않으면 PDF에서 찾는다. 지어낸 예:

| 보장명 | 지급사유 | 지급금액 |
| --- | --- | --- |
| 가나 진단비 | 가나병으로 진단 확정된 경우 | 가입금액(가입 1년 안에는 주1)가입금액의 50%) |

표 아래: "주1) 가나 사고로 생긴 경우에는 감액하지 않음"

```json
{"번호": "R001-1", "쪽": 12, "꼴": "가입금액비율", "지급률": 100,
 "감액": [{"기간": 1, "단위": "년", "값": 50, "값기준": "가입금액"}],
 "감액예외": [{"대상": "가나 사고", "자리": "주석"}]}
```

### 5.4 이름이 같은 세부보장

보장명 칸 하나가 지급사유 여러 행에 걸쳐 병합되면 같은 이름의 세부보장이 한 조각에 둘 이상 나온다. 묶음에는 `"이름같은줄": true`가 붙어 있다. 번호가 다르므로 줄마다 따로 읽고, 이름은 바꾸지 않고 `대상` 칸으로 가른다(4.11절).

### 5.5 형과 공통

형 구간이 있는 요약서는 조각에 `형`이 붙어 있다(예: 통합간편심사형, 공통). 같은 이름의 특약이 형마다 따로 나오므로, PDF를 열 때 그 쪽이 맞는 형 구간인지 쪽 머리의 형 표시로 확인한다.

### 5.6 면책기간 표와 보장개시일 나열 문장

면책 날수가 그 줄에 없고 다른 쪽에만 있는 경우가 둘 있다. 둘 다 `면책근거쪽`에 그 쪽을 적는다.

지어낸 예 1. 면책기간 표(요약서 앞쪽에 보장명마다 면책기간과 감액을 모아 둔 표)

| 보장명 | 면책기간 | 1년 이전 감액 |
| --- | --- | --- |
| 가나진단비 | 90일 | 가입금액의 50% |
| 다라진단비 | - | 가입금액의 50% |

가나진단비 줄의 지급사유가 "가나보장개시일 이후"면 `면책일수: 90`, `보장개시일: "가나보장개시일"`, `면책근거쪽`은 이 표가 있는 쪽이다. 코드는 그 쪽에서 보장명 바로 옆 칸의 날수를 본다.

지어낸 예 2. 보장개시일 나열 문장

"가나보장개시일, 다라보장개시일 및 마바보장개시일은 계약일부터 90일이 지난날의 다음날로 하며, 사아보장개시일은 계약일부터 1년이 지난날의 다음날로 합니다."

다라보장개시일이면 `90`, 사아보장개시일이면 `365`. 코드는 이름마다 그 이름이 든 나열의 "은/는" 뒤에 처음 나오는 날수와 짝짓는다. "가다라보장개시일"처럼 더 긴 이름 속에 든 글자는 그 이름으로 세지 않는다.

## 7. 견줌과 판정(메인 세션이 하는 일)

판독이 끝나면 메인 세션이 두 판독 파일을 견준다. 판독 폴더에서 묶음마다 `<묶음>.<판독자>.json`을 찾는다.

```bash
PYTHONPATH=src python scripts/compare_readers.py <묶음 파일> --answers <판독 폴더> --readers sonnet opus \
  --pieces <조각 파일> --page-text <쪽별 글자 JSON> --out <값 파일.jsonl> --report <견줌 결과.json>
```

`--pieces`에는 묶음을 나눈 원래 조각 파일(`scripts/dump_tables.py`나 `dump_blocks.py`의 결과)을 준다. 견줌 도구가 줄마다 `조각지문`을 그 조각으로 만들어 값 파일에 쓴다. 적재는 받은 요약서에서 다시 만든 조각과 이 지문을 맞추므로, 빠뜨리면 모든 줄이 "조각 지문이 다름"으로 빠진다. 묶음의 번호가 조각 파일에 없거나 세부보장명이 다르면 값 파일을 쓰지 않는다.

- 두 판독의 견줄 칸이 모두 같고, 두 판독 모두 기계 검사의 문제와 표시가 없으면 자동판정이 확정이다. 행없음 줄은 사유와 면책일수, 보장개시일, 한도를 견준다. 주의에 `세부보장여럿묶임`이나 `그밖`이 있는 줄, 행없음사유가 `그밖`인 줄은 같아도 메인 세션이 본다.
- 이름이 같은 세부보장은 판독마다 대상이 모두 있고 서로 달라야 확정된다. 대상이 서로 다르면 값이 달라도 갈림으로 세지 않는다.
- 기계 검사는 두 판독이 같은 방식으로 틀리는 것을 잡는다: 적은 숫자가 그 줄의 글자에 숫자 경계까지 있는가, 지급금액 칸에 있는 비율과 금액 가운데 판독이 쓰지 않은 것이 남는가, 감액 비율과 기간이 범위 안인가, 면책 날수가 그 줄과 주석이나 면책근거쪽(정의 문장, 나열 문장, 면책기간 표)에 그 이름의 날수로 있는가, 지급사유 본문(또는 지급금액 칸)이 보장개시일을 가리키는데 면책이 0인가, 지급사유 본문과 지급금액 칸에 감액이나 한도를 가리키는 말이 있는데 그 칸이 비었는가(빠진 값. 칸 안 표의 항목마다 한도가 걸리는 행없음은 한도를 보지 않고, 지급단위가 1회당이고 지급사유가 "수술은 1회당, 수술 이외의 치료는 연간 1회한" 꼴인 줄은 수술 이외 토막의 한도를 보지 않는다), 감액이 있는데 그 특약의 주석이 갱신계약에는 감액을 적용하지 않는다고 하고 감액예외에 갱신계약이 없는가(빠진 값), 특약명이나 세부보장명의 표식(연간N회한, 최초1회한, N일한도, 감액기간미적용, 면책기간미적용, 일당)과 값이 어긋나는가(이름 표식), 지급단위가 지급금액 칸의 단위와 맞는가, 한도와 지급단위와 감액예외의 구절을 글자에서 찾을 수 있는가, 대상 낱말이 그 줄에 있는가, 지급사유에서 대상 바로 뒤에 제외 단서 괄호가 이어지는데 대상에 없는가, 한 조각 안의 이름이 같은 세부보장이 서로 다른 값으로 갈리는가.
- 그 밖의 줄은 메인 세션이 PDF의 그 쪽을 보고 값 파일의 `판정` 칸을 채운다: `확정`, 판독자 이름(그 판독의 값을 씀), `수정`(`판정값`에 고친 값), `검토 대기`.
- 지급단위가 그 줄의 칸에 없고 같은 상품의 다른 문서(약관의 그 특약 조항 따위)에서 확인되면, `수정`의 `판정값`에 지급단위와 함께 `지급단위근거: {"문서": "약관", "쪽": N}`을 적는다(문서는 상품요약서, 사업방법서, 약관). 코드는 그 쪽에서 그 특약 이름에 "특약"이나 "특별약관"이 붙은 조항 제목이 줄 첫머리에 나오고 그 뒤에 지급단위 구절이 있는지 보고, 그 구절을 지급횟수제한 칸에 함께 싣는다. 판독자는 이 칸을 쓰지 않는다(4.5절대로 `모름`에 적는다).
- 값 파일에는 원문 구절이 없다. 숫자, 허용값, 짧은 낱말과 이름만 있다.
- 행 만들기(`reader_rows.build_rows`)는 갱신형 특약의 갱신주기년을 인자로 받는다. 값은 사람이 정하고, 주지 않은 갱신형 특약은 행을 만들지 않고 사유와 수를 남긴다.
