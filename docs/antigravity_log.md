# Antigravity 작업 기록

## 2026-11-21 시안 4 점검과 수정 (`site/proto/console4.html`)

### 1. 한 일과 전후 비교

1. 브리핑(`tab1`) 다섯째 줄이 1920x1080 첫 화면에 들어오게 조정
   - 고치기 전: 1920x1080 기준 조건(50세 남성, 이력 없음)에서 위 띠(76px), 조건 줄(85.6px), 두 줄로 꺾인 범위 띠(87~111.6px), 제목과 지표 묶음(155.7px), 지표 풀이(133.8px) 아래로 분석 요약이 놓이면서 다섯째 줄 `05 영업 인사이트`의 아래 끝이 `y = 1156.7~1212.6px`까지 내려가 첫 화면(1080px) 밖으로 넘어갔습니다. 치료 여정 막대(`kpiSel = 2`)도 막대 상자 높이(48px)보다 막대 최대 높이(64px)가 커서 위로 삐져나왔습니다.
   - 고친 내용: 문장과 글자 크기 하한(13px), 입력 요소 누르는 높이(40px)는 그대로 두고 `style.css`와 `tab1.css`, `tab1.js`에서 위쪽 여백과 패딩, 범위 띠 오른쪽 여백, 지표 고리 크기(72px에서 58px), 지표 풀이 패딩, 요약 줄 사이 높이를 줄였습니다. 치료 여정 막대 최대 높이도 상자 높이(40px)에 맞췄습니다.
   - 고친 뒤: 기준 종형 다섯 가지와 지표 탭 세 가지를 모두 바꿔 본 결과, 1920x1080 첫 화면에서 다섯째 줄 `05 영업 인사이트`의 아래 끝이 `y = 930.8~953.8px`, 요약 패널 전체의 아래 끝이 `y = 973.8~1017.6px` 안에 들어옵니다.

2. 고객군과 시장(`tab2`)의 `관문만수집` 표시 추가
   - 고치기 전: `전체`와 `비갱신` 지도의 `입원 3개월~1년 전` 두 칸, `수술만 3개월~1년 전` 두 칸은 상대 회사에서 열리는 종형이 관문만 수집한 `한화생명 간편가입형(0년)`뿐인데도 칸 안과 근거 기둥 어디에도 그 안내가 없었습니다.
   - 고친 내용: `tab2.js`와 `tab2.css`에서 칸의 `관문만수집` 배열에 값이 있으면 칸 안에 점선 테두리의 `관문만 수집` 표식과 종형 이름(`한화생명 간편가입형(0년)`)을 함께 그리고, 지도 범례와 칸 목록 복사에도 반영했습니다. 칸을 눌렀을 때 열리는 근거 기둥의 머리 요약과 회사별 열린 종형 줄에도 `관문만 수집(담보 미수집)` 표지와 설명을 적었습니다.
   - 고친 뒤: `전체` 지도 네 칸(`ma0-0`, `ma0-1`, `ma6-0`, `ma6-1`)과 `비갱신` 지도 네 칸(`mn0-0`, `mn0-1`, `mn6-0`, `mn6-1`) 모두 칸 안에 표식과 종형 이름이 보이고, 근거 기둥에 `관문만 수집(담보 미수집)`이 표시됩니다.

3. 가입 관문(`tab3`)의 `관문전용` 표시 추가와 종형 이름 누락 수정
   - 고치기 전: 관문 나무에서 `관문전용`이 참인 한화생명 네 종형(`간편가입형(0년)`, `간편가입형(3년)`, `간편가입형(4년)`, `간편가입형(10년)`)에 `관문만 수집(담보 미수집)` 표시가 없었습니다. 또한 `HANWHALIFE_2597_267ee0`(`간편가입형(10년)`)은 `sales.json`의 `종형` 사전에 들어 있지 않아 관문 나무와 근거 기둥 제목에 내부 코드 `HANWHALIFE_2597_267ee0`이 그대로 찍혔고, 근거 문서 줄에도 적용일 빈칸(`적용 .`)이 남았습니다. `간편가입형(0년)`의 입원과 수술 질문 기간도 `0년 안`과 `자료 없음`으로 어색하게 적혔습니다.
   - 고친 내용: `tab3.js`와 `tab3.css`에서 `관문전용`이 참인 종형의 나무 칸과 근거 기둥 배지, 본문 설명, 범례에 `관문만 수집(담보 미수집)`을 표시했습니다. 종형 이름을 찾을 때 `sales.json`에 없으면 관문 자료(`T3.관문.I`)의 `이름`을 쓰도록 고쳤고, 적용일이 없을 때 빈 문구를 빼며, 질문 기간이 0년일 때 `묻지 않음(0년)`과 `입원과 수술 기간 질문 없음`으로 적었습니다.
   - 고친 뒤: 네 종형 모두 관문 나무와 근거 기둥에 한글 종형 이름과 `관문만 수집(담보 미수집)` 표지가 함께 나옵니다.

4. 내보내기 자료의 `주석` 넷을 화면에 추가
   - 고치기 전: `sales.json`의 `주석` 네 항목(`지도전제`, `간편청약제한`, `수술만행`, `일반심사`)이 화면 어디에도 그려지지 않았습니다.
   - 고친 내용: `core.js`와 `style.css`에 탭 이름으로 주석을 걸러 그리는 `ui.notes` 부품을 만들고, `tab2.js`의 고객군 지도 패널 아래(`고객군과 시장` 해당 네 항목)와 `tab3.js`의 관문 나무 패널 아래(`가입 관문` 해당 두 항목)에 제목, 본문, 출처를 작은 글(13px)로 배치했습니다.
   - 고친 뒤: 고객군과 시장 탭에 네 항목, 가입 관문 탭에 두 항목이 각 자료의 `탭` 값에 맞춰 표시됩니다.

5. 내부 식별자 노출과 좁은 화면 애니메이션 넘침 수정
   - 고치기 전: 전체 탭과 모든 선택 항목을 순회해 검사한 결과, 고객군과 시장 탭의 개정 변동 행(`rv0`~`rv19`)을 눌렀을 때 근거 기둥에 `표준담보 STD_CA_HOSP_NURSING`처럼 내부 표준담보 ID가 찍혔고(`market` 소식 연결 시에도 같은 구조), 가입 관문 탭의 구성 예시 담보 행(`cg:...`)을 눌렀을 때도 근거 기둥에 `표준담보 STD_CA_DX_GENERAL`처럼 내부 ID가 그대로 노출되었습니다(다섯 기준 종형 합산 312회 검출). 또한 380x780 화면에서 아래쪽 근거 시트가 갱신될 때 가로 이동 애니메이션(`translateX(24px)`)이 돌아 화면 오른쪽 밖으로 8~12px 삐져나왔습니다.
   - 고친 내용: `tab2.js`(`revSpec`, `newsSpec`)와 `tab3.js`(`comboGroupSpec`)에서 내부 ID 대신 표준담보 한글 이름과 분류가 나오도록 바꿨고, `style.css`의 999px 이하 구간에서 근거 시트 갱신 애니메이션을 세로 이동(`translateY(12px)`)으로 바꿨습니다.
   - 고친 뒤: 다섯 기준 종형과 다섯 탭의 모든 선택 항목을 전수 검사했을 때 내부 ID(`EPOST_`, `HANWHALIFE_`, `SAMSUNGFIRE_`, `STD_` 등) 노출이 0건이고, 380x780 시트 전환 때도 가로 넘침이 없습니다.

6. 처음 보는 사람을 위한 다섯 용어의 물음표 풀이 추가
   - 더한 내용: `범위 띠`(범위 띠 왼쪽 머리), `관계와 근거 패널`(근거 기둥 위쪽 머리), `기준 종형과 선택 종형`(조건 줄의 기준 종형 이름 옆), `치료 여정 격자`(담보 비교 탭의 격자 제목 옆), `단정 주의와 검토 대기`(담보 비교 탭의 구역 머리 제목 옆) 다섯 곳에 작은 네모 물음표 단추(`.qhelp`)를 달았습니다. 누르면 화면을 가리지 않는 작은 풀이 상자(`#help-pop`, 화면 넓이의 1.5~4% 안쪽)에 한두 문장 설명이 열리고, 바깥을 누르거나 스크롤하거나 `Escape`를 누르면 열린 근거 기둥을 유지한 채 풀이 상자만 닫힙니다.

### 2. 확인한 방법

- 합치기 검사: `python proto_src/console4/gen_cover.py --assemble` 뒤 `python proto_src/console4/build.py` 실행. 외부 주소, 가운뎃점 나열, 엠대시, 금지 표현, 글꼴 누락 한글 검사 모두 오류 0건, 경고 0건으로 통과.
- 네 창 크기(1920x1080, 1600x900, 1280x800, 380x780) 브라우저 자동 점검(Playwright):
  - 다섯 탭 전환, 기준 종형 다섯 가지 전환, 조건 줄 입력 변경, 모든 `[data-pick]` 항목 선택, 다섯 용어 물음표 풀이 열기와 `Escape` 닫기 동작 확인.
  - 콘솔 오류 0건, 외부 네트워크 요청 0건, 문서 가로 넘침(`scrollWidth - clientWidth`) 0px, 내부 ID 노출 0건, 본문과 근거 기둥의 판정 불일치 0건 확인.
- 색 면적과 명암비 점검(`python proto_src/console4/shoot.py`):
  - 밝은 스킨과 짙은 스킨, 1920x1080, 1600x900, 1280x800, 1180x820, 380x780 전 구간에서 거의 흰 면 비율 최대 5.61%(기준 10% 안쪽), 빨강 면 비율 최대 1.81%(기준 2.5% 이하), 글자 명암비 기준 미달 0건, 콘솔 오류와 외부 요청 0건 확인.
- 저장소 전체 시험: `python -m pytest -q` 실행 결과 1,006개 통과.
