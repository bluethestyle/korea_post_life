# 우체국보험 상품·청약 판단 지원 앱 — 발표 시연 애니메이션 스토리보드 (3D 다큐멘터리 · 줌 투어 강화판)

본 영상은 정적 표·글머리표 위주의 발표 슬라이드 사이사이에 삽입하여 원리와 인과관계를 입체 공간·차트·카메라 워킹으로 직관적으로 보여주는 **3Blue1Brown 스타일 3차원(`ThreeDScene`) 기하학·인포그래픽 다큐멘터리 애니메이션**입니다.

전체 서사는 다음 4단계 흐름을 따릅니다:
1. **우리가 만들려는 서비스** (`1장`)
2. **구현하려는 핵심 기능들** (`2장`)
3. **각 프로세스에서 활용 가능한 자원과 직면한 현실 문제 → 그래서 어떻게 만들었는지** (`3장~8장`)
4. **결과적으로 기존에는 없거나 · 안 되거나 · 문제 있던 업무가 어떻게 새로워지고 개선되었는지** (`9장`)

## 장별 3D 공간 · 카메라 연출 설계

### Part 1. 서비스 목표와 구현 기능 (`1~2장`)
- **1장. 우리가 만들려는 서비스 — 3D 공시 문서 협곡에서 이원화 판단 체계로**
  - **3D 조감 → 심층 다이브 · 패닝**: 19개 보험사의 최대 567쪽 공시 문서를 상징하는 **3차원 반투명 문서 기둥(`Prism`) 협곡**에서 출발해, 카메라가 기준 충돌 상자(`입원만 ≠ 입원·수술`, `통합 ≠ 분리`, `정액 ≠ 비율`) 내부로 **클로즈업 다이브**한 뒤 절단된 다리와 창구·FC 노드로 **수평 패닝**하며 현장 단절을 직관화.
  - **본부 화면 클로즈업 → A4 투사**: 본부 단독 판단 화면 내부로 **줌인**하여 3종 실시간 미니 차트(관문 게이트 · 76종 히트맵 · 실수령 계단 차트)가 작동하는 모습을 비춘 뒤, **줌아웃**과 함께 우측 **창구·FC A4 1매 응대 카드**로 황금 광선을 투사.
- **2장. 구현하려는 핵심 기능 — 3D 궤도형 조건 허브와 핵심 화면 줌 투어**
  - **3D 궤도 사령부 구도**: 기울어진 **3차원 궤도 고리**를 두른 중앙 공통 조건 허브(`50세 · 남성 · 간편 2년형`)에서 6방향 신호가 점화되고, 카메라가 `화면 ② 가입 적격·간편심사 관문`에서 `화면 ③ 표준담보 76종 비교표`로 **클로즈업 패닝 투어**한 뒤 전체 조감도로 복귀.

### Part 2. 수집 · 추출 프로세스의 현미경 진단과 3D 입체 스캔 해법 (`3~4장`)
- **3장. 수집 프로세스 — 현미경 줌인 진단과 3D 16개사 레이저 커튼 스캔**
  - **현미경 줌 투어**: 27개 점 중 23개가 붉게 변하는 기간 경과 기사 행렬로 **밀착 줌인**한 뒤, 상단 한화손보 `400 차단` 벽으로 **수직 패닝**하여 장애 원인을 부각.
  - **3D 지형 스캔 · 게이트 추적**: 4단계 에이전트 분업 파이프라인에 이어 **3차원 16개사 기둥 지형 위를 수직 레이저 커튼 2개(수집 파동 · 독립 재호출 해시 검증 파동)가 횡단**하며 14개 기둥을 황금 검증 상태로 융기시키고, 요일별 순환 레이더와 3단계 물리 게이트 입자 차단을 클로즈업 추적.
- **4장. 추출 프로세스 — 3D 계단 지급액 블록과 3D 직교 레이저 교차 판독**
  - **모자이크 줌인 & 3D 계단 블록**: 308쪽 조각 그림 모자이크 타일로 **현미경 줌인** 후, 원문 추출 스텐실과 코드 계산 경로에서 **90일 면책 → 1년 미만 50% 감액(`1,000만`) → 1년 경과 100%(`2,000만`) 3차원 계단형 볼륨 블록**을 입체 조망.
  - **3D 직교 레이저 & 불일치 스파이크 다이브**: 308쪽 이미지 요약서 격자 위로 모델 A·B의 **3차원 직교 레이저 평면**이 교차하며 어긋난 칸에서 **붉은 3D 불일치 기둥**이 솟구치고, 카메라가 확대경 원문 대조(`2,000만원 ✓`)로 **다이브**하여 오차 0건 확정 과정을 시각화.

### Part 3. 판정 전용 AI(`Jev → decision-1`) 3D 코어와 3D 황금 확률 첨탑 (`5~6장`)
- **5장. 판정 전용 AI의 등장 — 순차 생성 파동 패닝 대 3D 자이로 코어**
  - 기존 생성형 AI의 흔들리는 순차 생성 파동 클로즈업에서 `생성 제거` 화살표를 따라 **`Jev` 무출력 판정 엔진(`출력 토큰 = 0`)으로 수평 패닝** → **3차원 자이로 궤도 고리와 크리스탈 코어를 갖춘 `gemini-decision-1` 허브** 공전 후, 우측 `1,000문항 점 행렬`과 `y=x` 45° 확률 보정 곡선으로 **클로즈업 포커싱**.
- **6장. 검증·분류 프로세스 — 병목 온도계 줌인과 3D 24기둥 황금 확률 첨탑**
  - 묶음 질문 오류 누출(`0.80 통과?!`)과 분당 `50K` 상한을 뚫고 `79.98K/분`까지 치솟는 토큰 온도계 클로즈업 → **3차원 격자 위의 24개 호박색 확률 기둥 능선(`0.50~0.80` 정체)이 대칭 선택지 전환과 함께 단 하나의 거대한 3D 황금 첨탑(`0.94↑ vs 0.06↓`, 오류 437건 통과 0건)으로 솟구치는 핵심 입체 변환** → 3단계 입자 재추출 루프 및 60초 안전 토큰 창(`42K / 50K`) 카메라 추적.

### Part 4. 3D 적층 온톨로지 · 지식그래프 은하 다이브와 전후 업무 혁신 (`7~9장`)
- **7장. 온톨로지·단독 화면 프로세스 — 3D Z축 적층 평면과 54노드 3D 은하 공전**
  - 52종 사전 밖 1,951줄 넘침 및 `>4MB` 초과 막대 줌인 → **Z축으로 적층된 3장의 3차원 반투명 평면(원천 사실 `2.97MB` · 표준 기준 `76종` · 분석 시사점 `0MB 즉시 산출`)을 수직 광선 펄스가 관통**한 뒤 선명한 2D 계층도로 전개 → **실제 3차원 `(x, y, z)` 좌표에 배치된 54노드 지식그래프 은하(확정 3,807건 실선 · 검토 대기 672건 점선) 주위를 카메라가 공전**하고 사전 `52→76종` 확장으로 이어짐.
- **8장. 지식그래프 담보 분석과 실행 — 중심 허브 다이브 · 관문 조준경 줌 · 응대 카드**
  - 은하 중심의 **`뇌·심장질환 수술비` 허브로 카메라가 심층 다이브**한 뒤 다단계 합산 경로(`외견상 미보유 29→25종 규명`)로 펼쳐지고, 간편심사 4×2 관문 격자의 **`[20~80세 × 수술만 = 우체국 적격 ▲]` 조준경 줌인**에서 치료 여정 5단계 차트의 **`[통원 0종 공백]`으로 패닝**한 뒤 4대 실무 전략과 창구 A4 응대 카드로 수렴.
- **9장. 최종 업무 혁신 인포그래픽 — 도입 전 한계에서 도입 후 도넛 지표로의 트래킹 샷**
  - 좌측 도입 전 한계(`Before`) 클로즈업에서 출발해 **3줄기 변환 광선(`신설 ✓ · 해결 ✓ · 개선 ✓`)과 함께 우측으로 카메라가 트래킹**하며 달성률 도넛 지표(`308쪽 오차 0건 100%` · `오류 437건 차단 100%` · `미보유 29→25종 해명 86%`)를 비추고, 전체 조감 피날레(`자동 시험 608개 통과 · 외부 요청 0건`)로 완결.
